# 🗄️ Adatbázis II.

Az Adatbázis II. tantárgy a Schola 14-es évfolyamon a modern webes technológiákat és API-kat tanítja: React projektek létrehozása és deploymentje, REST API elvek, és Bootstrap 5 haladó szinten.

## Mit fogsz itt tanulni?

A React alapjainak megismerésétől a hosting-ra való buildelésen át a REST API elvekig és a Bootstrap 5 komponensek mélyebb megértéséig haladsz — ezek a modern full-stack fejlesztés alapkövei.
