# 🔷 C# (C-Sharp)

A C# tárgy a Schola Szoftverfejlesztő képzésen a Microsoft .NET ökoszisztéma alapjait és az objektumorientált programozást tanítja. Az órákat több tanár tartotta: Zoli, Ádám és az általános C# órák.

## Mit fogsz itt tanulni?

A C# szintaxisától és alapjaitól indulva haladsz az osztályok, metódusok, kollekciók és a .NET keretrendszer irányába. A Windows Forms vagy konzolos alkalmazások fejlesztése a végső cél.
