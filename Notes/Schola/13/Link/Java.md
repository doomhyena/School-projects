# ☕ Java

A Java tárgy a Schola Szoftverfejlesztő képzésen az objektumorientált programozás alapjait és haladó technikáit tanítja. Az órák két tanárral zajlottak: Dávid saját és Ádám óráin.

## Mit fogsz itt tanulni?

Az osztályok, objektumok, öröklés és metódusok alapjaitól indulva haladsz a tömbök, kivételkezelés és a Java fejlett API-jainak irányába. A két különböző tanár megközelítése kiegészíti egymást.
