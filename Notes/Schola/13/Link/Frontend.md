# 🎨 Frontend

A Frontend tárgy a Schola Szoftverfejlesztő képzésen a webes felhasználói felületek fejlesztését tanítja: HTML, CSS, Bootstrap és JavaScript segítségével. Az órákat Józsi (HTML, CSS, Bootstrap) és Ádám (JavaScript) tartotta.

## Mit fogsz itt tanulni?

A HTML struktúrától és CSS stílusoktól indulva haladsz a reszponzív dizájn (Bootstrap, Flexbox, Grid), a CSS haladó technikái és a JavaScript alapjai irányába. A tantárgy lefedi a modern weben szükséges összes alapvető frontend eszközt.
