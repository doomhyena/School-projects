# 💻 Szoftverfejlesztő és -tesztelő

A **Szoftverfejlesztő és -tesztelő** szakma napjaink egyik legégetőbb munkaerőpiaci kihívására, az informatikushiányra válaszol. Az IT az egyik legdinamikusabban fejlődő ágazat — elég csak az AI térhódítására gondolni. A szoftverfejlesztők azonban nem egyszerű programozók: terméket készítenek, végigkísérik a fejlesztés teljes folyamatát, és az AI-t nem versenytársként, hanem eszközként kezelik.

---

## Mit tanulsz a képzésen?

- **Adatbázis-kezelés** SQL és MySQL nyelven
- **Dinamikus weboldalak** létrehozása HTML5, CSS3, Bootstrap 5, JavaScript és PHP segítségével
- **Asztali alkalmazások fejlesztése** C#, Java és Python nyelveken
- **Hálózati alapismeretek** — elméleti és gyakorlati szinten
- **Szoftvertesztelés** elmélete és gyakorlata
- **IT alapismeretek** — hardver, szoftver, szoftverjog (GPL, LGPL, AGPL stb.)
- **Szakmai angol** nyelvtudás, ami állásinterjún is megállja a helyét
- **Csapatmunka** és együttműködést támogató eszközök (GitHub, Google rendszerek)

> A képzésen kiemelt szerepet kap a valós munkahelyi környezet szimulálása — minden végzett diák könnyebben tud majd érvényesülni a munkapiacon, vagy akár egyéni vállalkozást is indíthat.
