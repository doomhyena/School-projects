# 📖 Erről a vaultról

Ezek az [**Obsidian**](https://obsidian.md) alkalmazásban készített iskolai jegyzetek. Az Obsidian egy helyi, markdown-alapú tudásmenedzsment eszköz - a jegyzetek `.md` fájlok, amelyek `[[wiki linkekkel]]` kapcsolódnak egymáshoz, és gráf nézetben is megjeleníthetők.

## 📁 A vault tartalma

```
Notes/
├── Bláthy/          → Bláthy Ottó Titusz Informatikai Technikum - Rendszergazda
│   ├── Link/        → Tantárgy-összefoglalók (belépési pontok)
│   ├── prog-alapok/ → Python órajegyzetek
│   ├── halozatok-I/ → Hálózatok I. anyagok
│   ├── ikt-projektmunka-I/ → IKT Projektmunka I. anyagok
│   ├── szakmai-angol/      → Szakmai angol feladatok
│   └── Bláthy rendszergazda.md → Főoldal
│
└── Schola/          → Schola Szoftverfejlesztő és -tesztelő
    ├── 13/          → 13. évfolyam anyagai
    │   ├── Link/    → Tantárgy-összefoglalók
    │   ├── Programming/ → Java, Python, C#, PHP, Frontend, MySQL
    │   └── IKT/     → IKT anyagok, próbavizsga
    ├── 14/          → 14. évfolyam anyagai
    └── Schola Szoftver.md → Főoldal
```

## 🧭 Navigálás Obsidianban

| Művelet | Hogyan |
|---------|--------|
| Ugrás egy jegyzetre | Kattints egy `[[linkre]]` |
| Bármely fájl megnyitása | `Ctrl + O` |
| Keresés a vaultban | `Ctrl + Shift + F` |
| Gráf nézet (kapcsolatok) | `Ctrl + G` |
| Visszalépés | `Alt + ←` |
| Gyorsan ide | Bal oldali panel → fájlfa |

> [!tip] Minden tantárgynak van egy **Link/** mappában lévő összefoglaló fájlja, ami belépési pontként szolgál. Onnan érheted el az összes órajegyzetet.
