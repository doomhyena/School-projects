# 4.3.5 Forgalomirányítás 3. rétegbeli switch-en

## Mi az az irányított port (Routed Port)?

Ha a VLAN-on belüli forgalomirányítás (SVI) mellett **külső hálózatokhoz** is csatlakoztatni akarjuk a 3. rétegbeli switch-et (pl. routerhez vagy más 3. rétegbeli switch-hez), **irányított portot** kell létrehozni.

Az irányított port:
- Egy 2. rétegbeli switchport, amelyen a kapcsolási funkciót letiltjuk
- Ugyanúgy viselkedik, mint egy router fizikai Ethernet interfész
- IP-cím rendelhető hozzá

---

## Irányított port létrehozása

```
D1(config)# interface GigabitEthernet0/0/1
D1(config-if)# no switchport               ← ezzel alakul 3. rétegbeli interfésszé
D1(config-if)# ip address 10.10.10.2 255.255.255.0
D1(config-if)# no shutdown
D1(config-if)# exit
```

> **Különbség az SVI-től:** Az SVI egy VLAN-hoz rendelt logikai interfész. Az irányított port egy fizikai port, amelyet 3. rétegbeli interfésszé alakítunk.

---

## Mikor szükséges irányított port?

- Ha a 3. rétegbeli switch egy routerhez csatlakozik (pl. OSPF szomszédság)
- Ha a switch-nek külső hálózathoz van szüksége csatlakozásra (pl. internet)
- Amikor statikus vagy dinamikus forgalomirányítási protokollt (OSPF, EIGRP) kell futtatni a switch-en

---

## Az ip routing parancs szükséges

Irányított portok konfigurálása esetén is szükséges:

```
D1(config)# ip routing
```

---

## Összefoglalás: SVI vs. Irányított Port

| Jellemző | SVI | Irányított port |
|---|---|---|
| Típus | Logikai (virtuális) | Fizikai |
| Konfiguráció | `interface vlan X` | `no switchport` |
| Célja | VLAN-ok közötti belső irányítás | Külső hálózathoz (router) csatlakozás |
| Layer 2 kapcsolás | Igen (VLAN-on belül) | Nem (csak 3. réteg) |
