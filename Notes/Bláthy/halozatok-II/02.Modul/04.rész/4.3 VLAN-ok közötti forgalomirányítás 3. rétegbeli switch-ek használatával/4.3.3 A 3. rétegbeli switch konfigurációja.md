# 4.3.3 A 3. rétegbeli switch konfigurációja

## A konfiguráció 4 lépése

1. VLAN-ok létrehozása
2. SVI VLAN-interfészek konfigurálása
3. Hozzáférési portok beállítása
4. IP-alapú forgalomirányítás engedélyezése

---

## 1. lépés: VLAN-ok létrehozása

```
D1(config)# vlan 10
D1(config-vlan)# name LAN10
D1(config-vlan)# vlan 20
D1(config-vlan)# name LAN20
D1(config-vlan)# exit
```

---

## 2. lépés: SVI VLAN-interfészek konfigurálása

```
D1(config)# interface vlan 10
D1(config-if)# description Default Gateway SVI for 192.168.10.0/24
D1(config-if)# ip address 192.168.10.1 255.255.255.0
D1(config-if)# no shutdown
D1(config-if)# exit

D1(config)# interface vlan 20
D1(config-if)# description Default Gateway SVI for 192.168.20.0/24
D1(config-if)# ip address 192.168.20.1 255.255.255.0
D1(config-if)# no shutdown
D1(config-if)# exit
```

> **Rendszer üzenet:** A sikeres konfiguráció után megjelenik:
> `%LINEPROTO-5-UPDOWN: Line protocol on Interface Vlan10, changed state to up`

---

## 3. lépés: Hozzáférési portok beállítása

```
D1(config)# interface GigabitEthernet1/0/6
D1(config-if)# description Access port for PC1
D1(config-if)# switchport mode access
D1(config-if)# switchport access vlan 10
D1(config-if)# exit

D1(config)# interface GigabitEthernet1/0/18
D1(config-if)# description Access port for PC2
D1(config-if)# switchport mode access
D1(config-if)# switchport access vlan 20
D1(config-if)# exit
```

---

## 4. lépés: IP-alapú forgalomirányítás engedélyezése

```
D1(config)# ip routing
```

> ⚠️ **Ez a kritikus lépés!** Nélküle az SVI-k léteznek, de a switch nem irányít VLAN-ok között – csak felügyeleti célra használja az SVI-ket.

---

## Összefoglalás: teljes konfiguráció hatása

| Konfiguráció | Hatás |
|---|---|
| `vlan 10/20` | VLAN-ok létrehozva a switch-en |
| `interface vlan 10` + IP | SVI = PC1 alapértelmezett átjárója |
| `interface vlan 20` + IP | SVI = PC2 alapértelmezett átjárója |
| `switchport access vlan 10/20` | PC-k a megfelelő VLAN-okba kerülnek |
| `ip routing` | A switch 3. rétegen is forgalmaz VLAN-ok között |
