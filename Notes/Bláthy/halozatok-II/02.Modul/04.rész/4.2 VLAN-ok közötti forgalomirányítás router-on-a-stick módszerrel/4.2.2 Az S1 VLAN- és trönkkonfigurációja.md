# 4.2.2 Az S1 VLAN- és trönkkonfigurációja

## A konfiguráció lépései

Az S1 switch konfigurálása 4 lépésből áll:

1. VLAN-ok létrehozása és elnevezése
2. Felügyeleti interfész (SVI) konfigurálása
3. Hozzáférési portok beállítása
4. Trönkportok beállítása

---

## 1. lépés: VLAN-ok létrehozása

```
S1(config)# vlan 10
S1(config-vlan)# name LAN10
S1(config-vlan)# exit
S1(config)# vlan 20
S1(config-vlan)# name LAN20
S1(config-vlan)# exit
S1(config)# vlan 99
S1(config-vlan)# name Management
S1(config-vlan)# exit
```

> **Fontos:** A VLAN csak az alkonfigurációs módból való kilépés (`exit` vagy `end`) után jön létre!

---

## 2. lépés: Felügyeleti SVI konfigurálása

```
S1(config)# interface vlan 99
S1(config-if)# ip address 192.168.99.2 255.255.255.0
S1(config-if)# no shutdown
S1(config-if)# exit
S1(config)# ip default-gateway 192.168.99.1
```

---

## 3. lépés: Hozzáférési port beállítása

PC1 az Fa0/6 porton csatlakozik S1-hez, VLAN 10-ben:

```
S1(config)# interface fa0/6
S1(config-if)# switchport mode access
S1(config-if)# switchport access vlan 10
S1(config-if)# no shutdown
S1(config-if)# exit
```

---

## 4. lépés: Trönkportok beállítása

S1 F0/1 (S2 felé) és F0/5 (R1 felé) trönkként:

```
S1(config)# interface fa0/1
S1(config-if)# switchport mode trunk
S1(config-if)# no shutdown
S1(config-if)# exit

S1(config)# interface fa0/5
S1(config-if)# switchport mode trunk
S1(config-if)# no shutdown
S1(config-if)# end
```

---

## Összefoglalás

| Port | Funkció | VLAN / Mód |
|---|---|---|
| Fa0/6 | PC1 hozzáférési port | VLAN 10 (access) |
| Fa0/1 | S2 felé trunk | trunk |
| Fa0/5 | R1 felé trunk | trunk |
| VLAN 99 SVI | Felügyeleti interfész | 192.168.99.2/24 |
