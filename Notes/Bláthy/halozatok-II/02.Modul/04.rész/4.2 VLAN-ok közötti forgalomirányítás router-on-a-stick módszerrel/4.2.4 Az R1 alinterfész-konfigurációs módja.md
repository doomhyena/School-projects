# 4.2.4 Az R1 alinterfész-konfigurációs módja

## Alinterfész szintaxis

Az alinterfész létrehozásának parancsa:

```
Router(config)# interface interface-id.subinterface-id
```

Például: `interface G0/0/1.10` – ez a G0/0/1 fizikai interfész .10-es alinterfésze. **A szokás szerint az alinterfész száma egyezzen meg a VLAN számával** (bár ez nem kötelező).

---

## Minden alinterfészen két kötelező parancs

### 1. encapsulation dot1Q vlan-id

```
R1(config-subif)# encapsulation dot1Q 10
```

Beállítja, hogy az alinterfész melyik VLAN-ból fogad 802.1Q jelöléssel ellátott kereteket.

> Ha a natív VLAN-t a VLAN 1-től eltérőre kell beállítani, add hozzá a `native` kulcsszót:
> `encapsulation dot1Q 99 native`

### 2. ip address ip-cím alhálózati-maszk

```
R1(config-subif)# ip address 192.168.10.1 255.255.255.0
```

Az alinterfész IP-címe – ez lesz az adott VLAN alapértelmezett átjárója.

---

## R1 teljes alinterfész konfigurációja

```
R1(config)# interface G0/0/1.10
R1(config-subif)# description Default Gateway for VLAN 10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0
R1(config-subif)# exit

R1(config)# interface G0/0/1.20
R1(config-subif)# description Default Gateway for VLAN 20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 192.168.20.1 255.255.255.0
R1(config-subif)# exit

R1(config)# interface G0/0/1.99
R1(config-subif)# description Default Gateway for VLAN 99
R1(config-subif)# encapsulation dot1Q 99
R1(config-subif)# ip address 192.168.99.1 255.255.255.0
R1(config-subif)# exit

R1(config)# interface G0/0/1
R1(config-if)# description Trunk link to S1
R1(config-if)# no shutdown
R1(config-if)# end
```

> **Fontos:** A fizikai interfész (`no shutdown`) engedélyezése az összes alinterfészt is engedélyezi. Ha a fizikai interfészt letiltjuk, az összes alinterfész is leáll.

---

## Alinterfészek összefoglalása

| Alinterfész | VLAN | IP-cím | Szerepe |
|---|---|---|---|
| G0/0/1.10 | VLAN 10 | 192.168.10.1/24 | PC1 alapértelmezett átjárója |
| G0/0/1.20 | VLAN 20 | 192.168.20.1/24 | PC2 alapértelmezett átjárója |
| G0/0/1.99 | VLAN 99 | 192.168.99.1/24 | S1, S2 felügyeleti átjárója |
