# 4.2.5 A PC1 és PC2 közötti kapcsolat ellenőrzése

## Ellenőrzési módszer

A router-on-a-stick konfiguráció után a legegyszerűbb ellenőrzés a hosztok közötti **ping** parancs. Először ellenőrizzük a PC1 IP-konfigurációját, majd pingeljük PC2-t.

---

## PC1 IP-konfigurációjának ellenőrzése (Windows)

```
C:\Users\PC1> ipconfig

Windows IP Configuration
Ethernet adapter Ethernet0:
   IPv4 Address     : 192.168.10.10
   Subnet Mask      : 255.255.255.0
   Default Gateway  : 192.168.10.1
```

---

## PC1 → PC2 ping (VLAN 10 → VLAN 20)

```
C:\Users\PC1> ping 192.168.20.10

Pinging 192.168.20.10 with 32 bytes of data:
Reply from 192.168.20.10: bytes=32 time<1ms TTL=127
Reply from 192.168.20.10: bytes=32 time<1ms TTL=127
Reply from 192.168.20.10: bytes=32 time<1ms TTL=127
Reply from 192.168.20.10: bytes=32 time<1ms TTL=127

Packets: Sent = 4, Received = 4, Lost = 0 (0% loss).
```

A sikeres ping megerősíti, hogy a VLAN-ok közötti forgalomirányítás működik.

---

## PC1 → S1 felügyeleti IP ping (VLAN 10 → VLAN 99)

```
C:\Users\PC1> ping 192.168.99.2

Request timed out.
Request timed out.
Reply from 192.168.99.2: bytes=32 time=2ms TTL=254
Reply from 192.168.99.2: bytes=32 time=1ms TTL=254
```

> **Megjegyzés:** Az első 1-2 csomag időtúlléphet az ARP-feloldás és a MAC-cím tábla feltöltése miatt. Ez normális.

---

## TTL értékek magyarázata

| TTL érték | Jelentés |
|---|---|
| `TTL=127` | A csomag átment a routeren (router csökkentette eggyel a 128-ból) |
| `TTL=254` | Lokális hálózaton maradt (255 – 1 = 254) |
