# 4.2.6 A router-on-a-stick VLAN-ok közötti forgalomirányítás ellenőrzése

## Show parancsok a router-on-a-stick ellenőrzéséhez

| Parancs | Hol? | Mit mutat? |
|---|---|---|
| `show ip route` | R1 | Forgalomirányítási tábla – alinterfészek útvonalai |
| `show ip interface brief` | R1 | Alinterfészek IP-cím és állapot |
| `show interfaces g0/0/1.10` | R1 | Egy adott alinterfész részletei |
| `show interfaces trunk` | S1 | Aktív trönkkapcsolatok és VLAN-ok |

---

## show ip route

```
R1# show ip route | begin Gateway

Gateway of last resort is not set

C   192.168.10.0/24 is directly connected, GigabitEthernet0/0/1.10
L   192.168.10.1/32 is directly connected, GigabitEthernet0/0/1.10
C   192.168.20.0/24 is directly connected, GigabitEthernet0/0/1.20
L   192.168.20.1/32 is directly connected, GigabitEthernet0/0/1.20
C   192.168.99.0/24 is directly connected, GigabitEthernet0/0/1.99
L   192.168.99.1/32 is directly connected, GigabitEthernet0/0/1.99
```

> **C** = közvetlenül csatlakoztatott, **L** = helyi (loopback-szerű) cím. Minden VLAN alinterfészen megjelenik.

---

## show ip interface brief (szűrve)

```
R1# show ip interface brief | include up

GigabitEthernet0/0/1   unassigned   YES unset  up  up
Gi0/0/1.10             192.168.10.1 YES manual up  up
Gi0/0/1.20             192.168.20.1 YES manual up  up
Gi0/0/1.99             192.168.99.1 YES manual up  up
```

Minden alinterfész `up/up` állapotban van és helyes IP-vel rendelkezik.

---

## show interfaces trunk (S1-en)

```
S1# show interfaces trunk

Port   Mode  Encapsulation  Status    Native vlan
Fa0/1  on    802.1q         trunking  1
Fa0/5  on    802.1q         trunking  1

Port   Vlans allowed on trunk
Fa0/1  1,10,20,99
Fa0/5  1,10,20,99

Port   Vlans in spanning tree forwarding state and not pruned
Fa0/1  1,10,20,99
Fa0/5  1,10,20,99
```

> **Megjegyzés:** A VLAN 1 automatikusan bekerül az engedélyezett listára (vezérlőforgalom mindig VLAN 1-en megy).

---

## Összefoglalás: mit ellenőrizz?

1. **show ip route** → Minden VLAN alinterfészén megjelenik útvonal (`C`)
2. **show ip interface brief** → Alinterfészek `up/up` és helyes IP-vel
3. **show interfaces trunk** → Az S1 trönkportjain a szükséges VLAN-ok engedélyezve vannak
4. **ping** PC-ről → Sikeres válasz a másik VLAN-ban lévő eszköztől
