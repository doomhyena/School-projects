# 4.4.4 Switch trönkportjával kapcsolatos problémák

## A probléma

A router-on-a-stick megoldásban a leggyakoribb trönkporttal kapcsolatos hiba: az R1-hez csatlakozó **S1 Fa0/5 port véletlenül le lett kapcsolva** (shutdown állapotban van).

---

## Tünetek

PC1 korábban el tudta érni más VLAN-okban lévő hosztokat, de egy karbantartás után a kapcsolat megszakadt. A karbantartási naplók szerint az S1-en konfigurációs módosítás történt.

---

## Diagnosztika

### show interfaces trunk

```
S1# show interfaces trunk

Port  Mode  Encapsulation  Status    Native vlan
Fa0/1  on   802.1q         trunking  1

Port  Vlans allowed on trunk
Fa0/1  1-4094
```

**Az Fa0/5 port (R1 felé) hiányzik a kimenetből!**

---

### show running-config interface fa0/5

```
S1# show running-config | include interface fa0/5

Building configuration...
interface FastEthernet0/5
 description Trunk link to R1
 switchport mode trunk
 shutdown                     ← HIBA: le van kapcsolva!
end
```

---

## A javítás

```
S1(config)# interface fa0/5
S1(config-if)# no shutdown
```

**Rendszer üzenet:**

```
%LINK-3-UPDOWN: Interface FastEthernet0/5, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface FastEthernet0/5, changed state to up
```

---

## Ellenőrzés

```
S1# show interfaces trunk

Port  Mode  Encapsulation  Status    Native vlan
Fa0/1  on   802.1q         trunking  1
Fa0/5  on   802.1q         trunking  1      ← most már megjelenik!

Port  Vlans allowed on trunk
Fa0/1  1-4094
Fa0/5  1-4094
```

---

## Tipp a redundanciához

Ha szeretnéd csökkenteni annak kockázatát, hogy egy ilyen hiba VLAN-ok közötti leállást okoz, **redundáns switch-kapcsolatokat** kell tervezni a hálózatba.
