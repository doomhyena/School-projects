# 4.4.5 A switch hozzáférési portjával kapcsolatos problémák

## A probléma

PC1 helyes IPv4-címmel és alapértelmezett átjáróval rendelkezik, de **nem tudja pingálni a saját alapértelmezett átjáróját** (192.168.10.1). A PC1-et az S1 Fa0/6 portján kellene a VLAN 10-be besorolni.

---

## Diagnosztika

### show interfaces fa0/6 switchport

```
S1# show interfaces fa0/6 switchport

Name: Fa0/6
Switchport: Enabled
Administrative Mode: static access
Operational Mode: static access
Access Mode VLAN: 1 (default)      ← HIBA: VLAN 1-ben van, nem VLAN 10-ben!
Trunking Native Mode VLAN: 1 (default)
Voice VLAN: none
```

---

### show running-config interface fa0/6

```
S1# show running-config interface fa0/6

Building configuration...
interface FastEthernet0/6
 description PC-A access port
 switchport mode access
 end
```

**Hiba:** A VLAN-hozzárendelés (`switchport access vlan 10`) hiányzik!

---

## A javítás

```
S1# configure terminal
S1(config)# interface fa0/6
S1(config-if)# switchport access vlan 10
```

---

## Ellenőrzés

```
S1(config-if)# do show interfaces fa0/6 switchport

Name: Fa0/6
Switchport: Enabled
Administrative Mode: static access
Operational Mode: static access
Access Mode VLAN: 10 (VLAN0010)    ← most már VLAN 10-ben van!
```

PC1 most már el tudja pingálni az alapértelmezett átjáróját és más VLAN-okban lévő hosztokat.

---

## Összefoglalás

| Tünet | Ok | Javítás |
|---|---|---|
| PC nem pingálheti az átjáróját | Port nincs a megfelelő VLAN-ban rendelve | `switchport access vlan 10` |
| `Access Mode VLAN: 1 (default)` | Elfelejtették a VLAN-hozzárendelést | Adjuk hozzá a parancsot |
