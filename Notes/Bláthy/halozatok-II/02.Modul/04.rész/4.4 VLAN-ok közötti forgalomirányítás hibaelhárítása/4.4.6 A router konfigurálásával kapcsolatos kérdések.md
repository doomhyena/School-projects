# 4.4.6 A router konfigurálásával kapcsolatos kérdések

## A probléma

R1-nek VLAN-ok közötti forgalomirányítást kell biztosítania a VLAN 10, 20 és 99 felhasználóinak. A VLAN 10 felhasználói azonban nem érnek el más VLAN-t.

---

## Diagnosztika

### 1. Trönkport ellenőrzése (S1)

A switch trönkkapcsolata rendben van – ez nem a hiba oka.

### 2. show ip interface brief (R1)

```
R1# show ip interface brief

Interface         IP-Address     OK? Status    Protocol
Gi0/0/1           unassigned     YES           up        up
Gi0/0/1.10        192.168.10.1   YES manual    up        up
Gi0/0/1.20        192.168.20.1   YES manual    up        up
Gi0/0/1.99        192.168.99.1   YES manual    up        up
```

Az alinterfészek helyes IP-vel rendelkeznek és `up` állapotban vannak.

### 3. show interfaces | include Gig|802.1Q

```
R1# show interfaces | include Gig|802.1Q

GigabitEthernet0/0/1 is up, line protocol is up
  Encapsulation 802.1Q Virtual LAN, Vlan ID  1.
GigabitEthernet0/0/1.10 is up, line protocol is up
  Encapsulation 802.1Q Virtual LAN, Vlan ID  100.    ← HIBA! 100-as VLAN, nem 10!
GigabitEthernet0/0/1.20 is up, line protocol is up
  Encapsulation 802.1Q Virtual LAN, Vlan ID  20.
GigabitEthernet0/0/1.99 is up, line protocol is up
  Encapsulation 802.1Q Virtual LAN, Vlan ID  99.
```

> **A probléma:** A G0/0/1.10 alinterfész **VLAN 100-hoz** van rendelve `encapsulation dot1Q 100` helyett `encapsulation dot1Q 10`!

### 4. show running-config interface g0/0/1.10

```
R1# show running-config interface g0/0/1.10

interface GigabitEthernet0/0/1.10
 description Default Gateway for VLAN 10
 encapsulation dot1Q 100           ← elírás: 100, nem 10!
 ip address 192.168.10.1 255.255.255.0
end
```

---

## A javítás

```
R1# configure terminal
R1(config)# interface gigabitEthernet 0/0/1.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# end
```

---

## Ellenőrzés

```
R1# show interfaces | include Gig|802.1Q

GigabitEthernet0/0/1.10 is up, line protocol is up
  Encapsulation 802.1Q Virtual LAN, Vlan ID  10.    ← most már helyes!
GigabitEthernet0/0/1.20 is up, line protocol is up
  Encapsulation 802.1Q Virtual LAN, Vlan ID  20.
```

VLAN 10 felhasználói (PC1) most már el tudják érni a többi VLAN-t.

---

## Összefoglalás: Pipe szűrő tipp

A `show interfaces | include Gig|802.1Q` parancs hasznos módszer az alinterfészek VLAN-hozzárendelésének gyors ellenőrzéséhez – csak a releváns sorokat jeleníti meg.
