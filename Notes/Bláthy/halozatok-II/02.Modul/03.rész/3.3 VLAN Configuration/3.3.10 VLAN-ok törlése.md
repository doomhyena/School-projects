# 3.3.10 VLAN-ok törlése

## Egy VLAN törlése

Egy adott VLAN eltávolítása a `no vlan` paranccsal:

```
S1(config)# no vlan 20
```

> ⚠️ **Figyelem!** Törlés előtt **mozgasd át** az összes portot más VLAN-ba! Ha egy porthoz törölt VLAN van rendelve, az a port **nem tud kommunikálni** amíg aktív VLAN-hoz nem rendelik.

---

## A teljes vlan.dat fájl törlése

Az összes VLAN konfiguráció visszaállítható a gyári alapértelmezett állapotba:

```
S1# delete flash:vlan.dat
```

Vagy rövidített formában (ha a fájl az alapértelmezett helyen van):

```
S1# delete vlan.dat
```

A switch újraindítása után az összes konfigurált VLAN eltűnik – a switch gyári alapértelmezett VLAN-beállítással indul.

---

## Teljes visszaállítás gyári alapértelmezettre

Ha teljesen gyári állapotba szeretnéd visszaállítani a switch-et (VLAN-ok + futó konfiguráció):

1. Húzz ki minden kábelt (konzol és tápkábel kivételével)
2. `S1# erase startup-config`
3. `S1# delete vlan.dat`
4. Újraindítás

---

## Mikor érdemes VLAN-t törölni?

- Ha egy projekt VLAN-ja már nem szükséges
- Ha tévesen hoztunk létre VLAN-t
- Ha a switch-et másik célra konfiguráljuk újra
