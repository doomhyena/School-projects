Az ábrán az S1 switch F0/6 portja hozzáférési portként van konfigurálva és a 20-as VLAN-hoz van hozzárendelve. Az adott porthoz csatlakoztatott összes eszköz a 20-as VLAN-hoz lesz társítva. Ezért példánkban PC2 a 20-as VLAN-hoz tartozik.
A példa az S1 konfigurációját mutatja, ahogy az F0/6 portot a 20-as VLAN-hoz rendeli.

```
S1# configure terminalS1(config)# interface fa0/6S1(config-if)# switchport mode accessS1(config-if)# switchport access vlan 20S1(config-if)# end
```

A VLAN-ok konfigurálása a switchporton történik, nem pedig a végberendezésen. PC2-t a switchporton beállított VLAN-hoz tartozó IPv4-címmel és alhálózati maszkkal konfiguráljuk. Ebben a példában ez a VLAN 20. A 20-as VLAN más switch-eken történő konfigurálásakor a hálózati rendszergazdának kell az egyéb hallgatói számítógépeket a PC2-vel egy alhálózaton (172.17.20.0/24) lévőnek beállítania.
