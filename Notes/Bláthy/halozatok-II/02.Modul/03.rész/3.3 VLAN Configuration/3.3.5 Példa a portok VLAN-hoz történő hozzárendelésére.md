# 3.3.5 Példa a portok VLAN-hoz történő hozzárendelésére

## Feladat

Az S1 switch F0/6 portjának hozzárendelése a VLAN 20-hoz (hallgatói VLAN).

---

## A konfigurációs parancsok

```
S1# configure terminal
S1(config)# interface fa0/6
S1(config-if)# switchport mode access
S1(config-if)# switchport access vlan 20
S1(config-if)# end
```

Az F0/6-hoz csatlakoztatott PC2 automatikusan a VLAN 20 tagja lesz.

---

## Fontos: az IP-cím konfigurálása

A VLAN-konfigurációt a switch-en végzik, **nem** a végberendezésen. A PC2-t viszont a VLAN 20-hoz tartozó IP-alhálózatban kell konfigurálni:

```
PC2 IPv4-cím: 172.17.20.22
Alhálózati maszk: 255.255.255.0
Átjáró: 172.17.20.1
```

Ha más switch-eken is vannak hallgatói portok, azokra is ugyanezt az alhálózatot kell beállítani.

---

## Ellenőrzés

```
S1# show vlan brief
VLAN Name            Status   Ports
---- --------------- -------  ----------------------------
1    default         active   Fa0/1, ... Fa0/5, Fa0/7 ... Fa0/24
20   student         active   Fa0/6
```
