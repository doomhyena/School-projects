# 3.3.8 VLAN-információk ellenőrzés

## A show vlan parancs

```
S1# show vlan [brief | id vlan-id | name vlan-name | summary]
```

### Lehetséges opciók

| Opció | Leírás |
|---|---|
| `brief` | Rövid összefoglaló: VLAN-ok neve, állapota, portjai |
| `id vlan-id` | Egy adott VLAN részletei (pl. `show vlan id 20`) |
| `name vlan-name` | Egy adott VLAN neve alapján (pl. `show vlan name student`) |
| `summary` | Összefoglaló statisztika a VLAN-okról |

---

## Példa: show vlan brief

```
S1# show vlan brief
VLAN Name              Status   Ports
---- ------------------ -------- ----------------------------
1    default            active   Fa0/1, Fa0/2 ...
20   student            active   Fa0/6
150  voice              active   Fa0/18
```

---

## Port részleteinek ellenőrzése

```
S1# show interfaces fa0/18 switchport
Name: Fa0/18
Switchport: Enabled
Administrative Mode: static access
Operational Mode: static access
...
Access Mode VLAN: 20 (student)
Voice VLAN: 150
```

---

## VLAN részleteinek ellenőrzése

```
S1# show interfaces vlan 20
Vlan20 is up, line protocol is up
  Hardware is EtherSVI, address is ...
  Internet address is 172.17.20.1/24
  ...
```
