# 3.3.2 VLAN létrehozási parancsok

## VLAN létrehozása és elnevezése

A VLAN-okat globális konfigurációs módból hozzuk létre. Bevált gyakorlat: **minden VLAN-nak adjunk nevet**.

### Szintaxis

```
Switch(config)# vlan [vlan-id]
Switch(config-vlan)# name [vlan-nev]
Switch(config-vlan)# end
```

### Több VLAN egyszerre

Egy paranccsal több VLAN-t is létrehozhatunk:

```
Switch(config)# vlan 100,102,105-107
```

Ez létrehozza a 100, 102, 105, 106 és 107-es VLAN-okat.

---

## Tárolás módja

- A normál tartományú VLAN-ok konfigurációja a **`vlan.dat`** fájlban tárolódik a flash memóriában
- Ez nem felejtős memória → **nem kell** a `copy running-config startup-config` parancs a VLAN-ok mentéséhez
- De mivel más konfigurációval párhuzamosan végezzük, **ajánlott** az aktív konfigurációt is menteni

---

## A VLAN konfiguráció ellenőrzése

```
S1# show vlan brief
VLAN Name            Status   Ports
---- --------------- -------  ---------
1    default         active   Fa0/1 ... Fa0/24
20   student         active   
99   management      active   
```
