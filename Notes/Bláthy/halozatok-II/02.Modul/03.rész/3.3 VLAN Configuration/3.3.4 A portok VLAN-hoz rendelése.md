# 3.3.4 A portok VLAN-hoz rendelése

## Hogyan rendeljük a portot egy VLAN-hoz?

A VLAN létrehozása után a switchportokat kell a megfelelő VLAN-okhoz rendelni. Ezt **interfész konfigurációs módból** végezzük.

---

## A parancsok szintaxisa

```
Switch(config)# interface [interface-id]
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan [vlan-id]
Switch(config-if)# end
```

### Parancsok magyarázata

| Parancs | Leírás |
|---|---|
| `switchport mode access` | A port hozzáférési módba kerül (nem egyeztet trönkről) |
| `switchport access vlan [id]` | A portot a megadott VLAN-hoz rendeli |

> **Biztonsági megjegyzés:** A `switchport mode access` opcionális, de ajánlott – megakadályozza, hogy a port trönk módra váltson (DTP egyeztetéssel).

---

## Több port egyszerre

Az `interface range` paranccsal több portot egyszerre konfigurálhatunk:

```
S1(config)# interface range Fa0/1 - 12
S1(config-if-range)# switchport mode access
S1(config-if-range)# switchport access vlan 10
```
