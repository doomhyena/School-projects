A **switchport voice vlan** _vlan-id_ interfészkonfigurációs paranccsal rendelhetünk hang VLAN-t egy porthoz.

A hangforgalmat támogató LAN-okban általában a szolgáltatásminőség (QoS) is engedélyezve van. A hangforgalmat megbízhatónak kell jelölni, amint belép a hálózatba. Az **mls qos trust [cos | device cisco-phone | dscp | ip-precedence]** interfészkonfigurációs paranccsal beállíthatjuk egy interfész megbízható állapotát, és megadhatjuk, hogy a csomag mely mezőit használja a forgalom osztályozására.

A példában szereplő konfiguráció létrehozza a két VLAN-t (azaz a VLAN 20-at és a VLAN 150-et), majd az S3 F0/18-as interfészét switchportként rendeli hozzá a VLAN 20-hoz. Emelett hangforgalmat rendel a VLAN 150-hez, és engedélyezi a QoS-osztályozást az IP-telefon által kijelölt szolgáltatási osztály (CoS) alapján.

```
S3(config)# vlan 20S3(config-vlan)# name studentS3(config-vlan)# vlan 150S3(config-vlan)# name VOICES3(config-vlan)# exitS3(config)# interface fa0/18S3(config-if)# switchport mode accessS3(config-if)# switchport access vlan 20S3(config-if)# mls qos trust cosS3(config-if)# switchport voice vlan 150S3(config-if)# endS3#
```
**MEGJEGYZÉS:** A QoS megvalósítása meghaladja ennek a tanfolyamnak a kereteit.

A **switchport access vlan** parancs kikényszeríti egy VLAN létrehozását, amennyiben az még nem létezik a switch-en. A VLAN 30 például nem jelenik meg a switch **show vlan brief** parancsának kimenetében. Ha a **switchport access vlan 30** parancsot olyan interfészen adjuk ki, amelyen nincs korábbi konfiguráció, akkor a switch a következőket jeleníti meg:

```
% Access VLAN does not exist. Creating vlan 30
```
