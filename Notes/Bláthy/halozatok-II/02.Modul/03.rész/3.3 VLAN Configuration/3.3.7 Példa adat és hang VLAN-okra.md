# 3.3.7 Példa adat és hang VLAN-okra

## A konfiguráció

Az S3 switch Fa0/18 portján adat VLAN (20) és hang VLAN (150) konfigurálása:

```
S3(config)# vlan 20
S3(config-vlan)# name student
S3(config-vlan)# vlan 150
S3(config-vlan)# name VOICE
S3(config-vlan)# exit

S3(config)# interface fa0/18
S3(config-if)# switchport mode access
S3(config-if)# switchport access vlan 20
S3(config-if)# mls qos trust cos
S3(config-if)# switchport voice vlan 150
S3(config-if)# end
```

---

## A parancsok magyarázata

| Parancs | Leírás |
|---|---|
| `switchport mode access` | A port hozzáférési módban van |
| `switchport access vlan 20` | Az adat forgalom VLAN 20-ra kerül |
| `mls qos trust cos` | Az IP-telefon CoS jelöléseiben megbízik (QoS) |
| `switchport voice vlan 150` | A hangforgalom VLAN 150-re kerül |

> **QoS megjegyzés:** Az `mls qos trust cos` engedélyezi a CoS alapú forgalomosztályozást. A QoS teljes megvalósítása meghaladja ennek a tanfolyamnak a kereteit.

---

## A konfiguráció ellenőrzése

```
S3# show interfaces fa0/18 switchport
Access Mode VLAN: 20 (student)
Voice VLAN: 150 (VOICE)
```
