# 3.3.9 Port VLAN-tagságának megváltoztatása

## Helytelen VLAN-hozzárendelés javítása

Ha egy switchport helytelenül van VLAN-hoz rendelve, egyszerűen adjuk meg újra a `switchport access vlan` parancsot a helyes VLAN-azonosítóval.

**Példa:** Az Fa0/18 port tévesen a VLAN 1-re van rendelve, de a VLAN 20-on kellene lennie:

```
S1(config)# interface fa0/18
S1(config-if)# switchport access vlan 20
S1(config-if)# end
```

---

## Visszaállítás az alapértelmezett VLAN 1-re

A `no switchport access vlan` parancs visszaállítja a portot az alapértelmezett **VLAN 1**-re:

```
S1(config)# interface fa0/18
S1(config-if)# no switchport access vlan
S1(config-if)# end
```

---

## Ellenőrzés visszaállítás után

```
S1# show vlan brief
VLAN Name            Status   Ports
---- --------------- -------  ----------------------------
1    default         active   ... Fa0/18 ...
20   student         active   
```

> **Fontos:** A VLAN 20 **továbbra is aktív** marad, annak ellenére, hogy nincs hozzárendelt port. A VLAN törlésére a `no vlan 20` parancs szolgál.

---

## Ellenőrzés show interfaces paranccsal

```
S1# show interfaces fa0/18 switchport
...
Access Mode VLAN: 1 (default)
...
```
