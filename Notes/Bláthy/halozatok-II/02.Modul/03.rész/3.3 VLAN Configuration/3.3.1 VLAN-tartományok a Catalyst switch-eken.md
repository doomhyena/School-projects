# 3.3.1 VLAN-tartományok a Catalyst switch-eken

## Hány VLAN fér el egy Cisco switch-en?

A Cisco Catalyst switch-ek a VLAN azonosítók alapján két tartományt kezelnek:

---

## Normál tartományú VLAN-ok (Normal Range)

| Jellemző | Érték |
|---|---|
| VLAN ID tartomány | **1 – 1005** |
| Felhasználás | Kis- és közepes vállalkozások, vállalati hálózatok |
| Tárolás helye | `vlan.dat` fájl a flash memóriában |
| VTP szinkronizáció | Igen, ha konfigurálva van |

**Fenntartott VLAN-ok:**
- **VLAN 1**: Alapértelmezett VLAN – nem törölhető, nem nevezhető át
- **VLAN 1002–1005**: Régi technológiák (Token Ring, FDDI) számára fenntartott – automatikusan jönnek létre, nem törölhetők

---

## Kiterjesztett tartományú VLAN-ok (Extended Range)

| Jellemző | Érték |
|---|---|
| VLAN ID tartomány | **1006 – 4094** |
| Felhasználás | Szolgáltatók, nagyvállalatok |
| Tárolás helye | Az aktív konfigurációban (`running-config`) |
| VTP szinkronizáció | Csak VTP transzparens módban |

> **Miért 4096 a maximum?** A 802.1Q tag VLAN ID mezője 12 bit → 2¹² = 4096 lehetséges érték (0–4095), de 0 és 4095 fenntartott, tehát ténylegesen 1–4094 használható.

---

## Az alapértelmezett VLAN-ok Catalyst 2960 switch-en (IOS 15.x)

```
Switch# show vlan brief
VLAN Name              Status   Ports
---- ----------------- -------  --------------------
1    default           active   Fa0/1 ... Fa0/24, Gi0/1, Gi0/2
1002 fddi-default       act/unsup
1003 token-ring-default act/unsup
1004 fddinet-default    act/unsup
1005 trnet-default      act/unsup
```
