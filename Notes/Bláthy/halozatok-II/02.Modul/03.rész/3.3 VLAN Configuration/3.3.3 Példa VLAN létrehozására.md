A topológiában a hallgatói számítógép (PC2) még nem lett VLAN-hoz rendelve, de már rendelkezik a 172.17.20.22 IP-címmel, amely a 20-as VLAN-hoz tartozik.

Az ábra azt szemlélteti, hogy miként kell az S1 switch-en a hallgatói VLAN-t (VLAN 20) beállítani.

```
S1# configure terminalS1(config)# vlan 20S1(config-vlan)# name studentS1(config-vlan)# end
```

**MEGJEGYZÉS:** Egyetlen VLAN ID bevitelén felül VLAN ID-k vesszővel elválasztott sorozatát, vagy kötőjellel elválasztott tartományát is megadhatjuk a **vlan** _vlan-id_ parancsban. Például a **vlan 100,102,105-107** globális konfigurációs parancs megadásával 100, 102, 105, 106 és 107-es VLAN-ok hozhatók létre.
