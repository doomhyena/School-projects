# 3.3.3 Példa VLAN létrehozására

## Feladat

A VLAN 20 (hallgatói) létrehozása az S1 switch-en.

---

## A VLAN 20 létrehozása

```
S1# configure terminal
S1(config)# vlan 20
S1(config-vlan)# name student
S1(config-vlan)# end
```

---

## Ellenőrzés

```
S1# show vlan brief
VLAN Name            Status   Ports
---- --------------- -------  ----------------------------
1    default         active   Fa0/1, Fa0/2, ... Fa0/24, Gi0/1, Gi0/2
20   student         active   
1002 fddi-default    act/unsup
1003 token-ring...   act/unsup
1004 fddinet...      act/unsup
1005 trnet-default   act/unsup
```

> **Fontos:** A VLAN 20 létezik, de még **nincs hozzá port rendelve** – ezt a következő lépésben kell elvégezni.

---

## VLAN létrehozásának mellékhatása

Ha a `switchport access vlan 30` parancsot adjuk ki egy porton, de a VLAN 30 **még nem létezik**, a switch automatikusan létrehozza és jelzi:

```
% Access VLAN does not exist. Creating vlan 30
```
