# 3.3.11 Parancsszimulátor – VLAN-konfiguráció

## A feladat célja

Ebben a szimulátorban a VLAN-ok teljes konfigurációs folyamatát gyakoroljuk egy Cisco switch-en: VLAN létrehozása, porthoz rendelés, adat- és hang VLAN egyidejű konfigurálása, majd eltávolítás és ellenőrzés.

---

## 1. feladat: Adat VLAN létrehozása (VLAN 20)

**Cél:** Hozz létre egy `student` nevű VLAN 20-at, majd ellenőrizd.

```
S1# configure terminal
S1(config)# vlan 20
S1(config-vlan)# name student
S1(config-vlan)# end
```

**Ellenőrzés:**

```
S1# show vlan brief

VLAN Name                             Status    Ports
---- -------------------------------- --------- -------------------------------
1    default                          active    Fa0/1-Fa0/24, Gi0/1, Gi0/2
20   student                          active
```

> **Megjegyzés:** A VLAN 20 aktív, de még nincs porthoz rendelve – a portok mind VLAN 1-en vannak.

---

## 2. feladat: Hang VLAN létrehozása (VLAN 150)

**Cél:** Hozz létre egy `VOICE` nevű VLAN 150-et.

```
S1# configure terminal
S1(config)# vlan 150
S1(config-vlan)# name VOICE
S1(config-vlan)# exit
```

---

## 3. feladat: Adat és hang VLAN hozzárendelése (Fa0/18)

**Cél:** Az Fa0/18 portot hozzáférési módba állítsd, rendeld hozzá VLAN 20-at (adat) és VLAN 150-et (hang).

```
S1(config)# interface fa0/18
S1(config-if)# switchport mode access
S1(config-if)# switchport access vlan 20
S1(config-if)# mls qos trust cos
S1(config-if)# switchport voice vlan 150
S1(config-if)# end
```

| Parancs | Hatás |
|---|---|
| `switchport mode access` | Port rögzítve hozzáférési módban |
| `switchport access vlan 20` | PC forgalma a VLAN 20-on megy |
| `mls qos trust cos` | IP-telefon CoS jelöléseit elfogadja (QoS) |
| `switchport voice vlan 150` | Hangforgalom a VLAN 150-en megy |

**Ellenőrzés:**

```
S1# show vlan brief

VLAN Name           Status   Ports
---- --------------- -------- --------------------------------
1    default         active   Fa0/1-Fa0/17, Fa0/19-Fa0/24...
20   student         active   Fa0/18
150  VOICE           active   Fa0/18
```

---

## 4. feladat: Adat VLAN eltávolítása a portról

**Cél:** Távolítsd el a VLAN 20-at az Fa0/18 portról (`no switchport access vlan`).

```
S1# configure terminal
S1(config)# interface fa0/18
S1(config-if)# no switchport access vlan
S1(config-if)# do show vlan brief
```

**Eredmény:** Az Fa0/18 visszakerül a VLAN 1-re, de a VLAN 150 (hang) megmarad:

```
1    default         active   ... Fa0/18 ...   ← Fa0/18 visszakerült VLAN 1-re
20   student         active                    ← nincs port hozzárendelve
150  VOICE           active   Fa0/18           ← hang VLAN megmarad
```

> **Megjegyzés:** A `no switchport access vlan` csak az adat VLAN-t távolítja el; a hang VLAN (`switchport voice vlan`) külön paranccsal távolítható el.

---

## 5. feladat: VLAN 20 hozzárendelése másik porthoz (Fa0/11)

```
S1(config-if)# interface fa0/11
S1(config-if)# switchport mode access
S1(config-if)# switchport access vlan 20
S1(config-if)# end
```

**Ellenőrzés:**

```
S1# show vlan brief

20   student         active   Fa0/11
150  VOICE           active   Fa0/18
```

---

## 6. feladat: Részletes ellenőrzési parancsok

**Egy névvel rendelkező VLAN megjelenítése:**

```
S1# show vlan name student

VLAN Name    Status   Ports
---- ------- -------- ---------------
20   student  active   Fa0/11, Fa0/18
```

**Összefoglaló statisztika:**

```
S1# show vlan summary

Number of existing VLANs : 7
Number of existing VTP VLANs : 7
Number of existing extended VLANS : 0
```

**Switchport részletek (Fa0/11):**

```
S1# show interfaces fa0/11 switchport

Name: Fa0/11
Switchport: Enabled
Administrative Mode: static access
Operational Mode: down
Administrative Trunking Encapsulation: dot1q
Operational Trunking Encapsulation: native
Negotiation of Trunking: Off
Access Mode VLAN: 20 (Students)
Trunking Native Mode VLAN: 1 (default)
Voice VLAN: none
```

---

## Összefoglalás

| Lépés | Parancs |
|---|---|
| VLAN létrehozása | `vlan 20` → `name student` |
| Port hozzáférési módba | `switchport mode access` |
| Adat VLAN hozzárendelése | `switchport access vlan 20` |
| Hang VLAN hozzárendelése | `mls qos trust cos` + `switchport voice vlan 150` |
| VLAN eltávolítása portról | `no switchport access vlan` |
| Ellenőrzés | `show vlan brief/name/summary`, `show interfaces switchport` |
