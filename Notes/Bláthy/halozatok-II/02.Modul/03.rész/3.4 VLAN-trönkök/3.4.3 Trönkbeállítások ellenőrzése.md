# 3.4.3 Trönkbeállítások ellenőrzése

## Az ellenőrzésre szolgáló parancs

```
S1# show interfaces fa0/1 switchport
```

Ez a parancs részletesen megmutatja az adott interfész összes switchport-beállítását, beleértve a trönk konfigurációt is.

---

## A parancs kimenete (magyarázattal)

```
Name: Fa0/1
Switchport: Enabled
Administrative Mode: trunk                    ← manuálisan trönkre állítva
Operational Mode: trunk                       ← ténylegesen trönkként működik
Administrative Trunking Encapsulation: dot1q  ← 802.1Q szabvány
Operational Trunking Encapsulation: dot1q
Negotiation of Trunking: On
Access Mode VLAN: 1 (default)
Trunking Native Mode VLAN: 99 (VLAN0099)      ← natív VLAN = 99
Voice VLAN: none
...
Trunking VLANs Enabled: 10,20,30,99           ← csak ezek a VLAN-ok mehetnek át
Pruning VLANs Enabled: 2-1001
```

---

## A kiemelt mezők értelmezése

| Mező | Jelentés |
|---|---|
| `Administrative Mode: trunk` | A port manuálisan trönk módra van konfigurálva |
| `Operational Mode: trunk` | A port ténylegesen trönk módban működik |
| `Administrative Trunking Encapsulation: dot1q` | A 802.1Q beágyazás van beállítva |
| `Trunking Native Mode VLAN: 99` | A natív (jelöletlen) VLAN a VLAN 99 |
| `Trunking VLANs Enabled: 10,20,30,99` | Csak ezek a VLAN-ok engedélyeztek a trönkön |

---

## Második ellenőrzési lehetőség

```
S1# show interfaces trunk
```

Ez a parancs összefoglalóan mutatja az összes aktív trönkinterfészt:

```
Port   Mode   Encapsulation  Status    Native vlan
Fa0/1  on     802.1q         trunking  99

Port   Vlans allowed on trunk
Fa0/1  10,20,30,99

Port   Vlans allowed and active in management domain
Fa0/1  10,20,30,99

Port   Vlans in spanning tree forwarding state and not pruned
Fa0/1  10,20,30,99
```

---

## Mit ellenőrizz egy trönk konfiguráció után?

1. **Administrative Mode = trunk** – manuálisan be van állítva
2. **Operational Mode = trunk** – ténylegesen trönként működik
3. **Trunking Native Mode VLAN** – egyezik a másik vég natív VLAN-jával
4. **Trunking VLANs Enabled** – csak a szükséges VLAN-ok szerepelnek
