# 3.4.4 A trönk visszaállítása alapértelmezett állapotra

## Mikor szükséges visszaállítani?

- Ha el akarjuk távolítani a VLAN-korlátozásokat a trönkről
- Ha a natív VLAN-t vissza akarjuk állítani az alapértelmezett VLAN 1-re
- Ha a trönk portból hozzáférési (access) portot szeretnénk csinálni

---

## 1. lépés: Engedélyezett VLAN-ok és natív VLAN visszaállítása

```
S1(config)# interface fa0/1
S1(config-if)# no switchport trunk allowed vlan
S1(config-if)# no switchport trunk native vlan
S1(config-if)# end
```

| Parancs | Hatás |
|---|---|
| `no switchport trunk allowed vlan` | Minden VLAN engedélyezett lesz (alapértelmezett) |
| `no switchport trunk native vlan` | A natív VLAN visszaáll VLAN 1-re |

**Ellenőrzés:**

```
S1# show interfaces fa0/1 switchport

Administrative Mode: trunk
Operational Mode: trunk
Trunking Native Mode VLAN: 1 (default)    ← visszaállt VLAN 1-re
Trunking VLANs Enabled: ALL               ← összes VLAN engedélyezett
```

---

## 2. lépés: Trönk port visszaállítása hozzáférési porttá

Ha teljesen le szeretnénk bontani a trönkot és a portot hozzáférési (access) módba tenni:

```
S1(config)# interface fa0/1
S1(config-if)# switchport mode access
S1(config-if)# end
```

**Ellenőrzés:**

```
S1# show interfaces fa0/1 switchport

Administrative Mode: static access        ← access módban van
Operational Mode: static access
Administrative Trunking Encapsulation: dot1q
Operational Trunking Encapsulation: native
Negotiation of Trunking: Off              ← DTP ki van kapcsolva
Access Mode VLAN: 1 (default)
Trunking Native Mode VLAN: 1 (default)
```

---

## Összefoglalás: trönk visszaállítás lépései

| Cél | Parancs |
|---|---|
| Engedélyezett VLAN-ok törlése | `no switchport trunk allowed vlan` |
| Natív VLAN visszaállítása | `no switchport trunk native vlan` |
| Port hozzáférési módba állítása | `switchport mode access` |

---

## Kapcsolódó: trönk port törlése a konfigurációból

Ha teljesen gyári állapotra szeretnéd visszaállítani a portot:

```
S1(config-if)# default interface fa0/1
```

Ez az interfész **összes konfigurációját** visszaállítja az alapértelmezett értékekre.
