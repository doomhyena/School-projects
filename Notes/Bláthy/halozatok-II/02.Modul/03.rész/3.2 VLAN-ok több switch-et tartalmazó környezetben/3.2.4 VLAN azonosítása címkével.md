A szabványos Ethernet keret fejléce nem tartalmaz információt arról, hogy a keret melyik VLAN-hoz tartozik. Ezért, ha az Ethernet kereteket egy trönkvonalra helyezzük, információt kell hozzáadni azokról a VLAN-okról, amelyekhez tartoznak. Ez a címkézésnek (tagging) nevezett folyamat az IEEE 802.1Q szabványban meghatározott IEEE 802.1Q fejléc használatával történik. A 802.1Q fejléc egy az eredeti Ethernet keret fejlécébe illesztett 4 bájtos címkét tartalmaz, amely beazonosítja azt a VLAN-t, amelyhez a keret tartozik.

Amikor a switch egy VLAN-hoz rendelt hozzáférési módú porton keretet fogad, akkor a keretfejlécbe egy VLAN-címkét szúr be, majd újraszámítja a keretellenőrző összeget (FCS), és a címkézett keretet egy trönkporton továbbküldi.

**VLAN Tag Field Details**

Amint az ábrán látható, a VLAN címkevezérlési információs mezője egy Típus (Type) mezőből, egy Prioritás (Priority) mezőből, egy Kanonikus formátumazonosító (Canonical Format Identifier) mezőből és egy VLAN-azonosító (VLAN ID) mezőből áll:

- **Type** - A 2-byte value called the tag protocol ID (TPID) value. Ethernet esetén az értéke hexadecimális 0x8100.
- **User priority** - A 3-bit value that supports level or service implementation.
- **Canonical Format Identifier (CFI)** - A 1-bit identifier that enables Token Ring frames to be carried across Ethernet links.
- **VLAN ID (VID)** - A 12-bit VLAN identification number that supports up to 4096 VLAN IDs.

Miután a switch beillesztette a címkevezérlési információs mezőket, újraszámolja az FCS-értéket, és elhelyezi azt a keret FCS-mezőjében.
