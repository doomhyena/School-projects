# 3.5.4 A DTP-mód ellenőrzése

## Az ellenőrzésre szolgáló parancs

```
S1# show dtp interface fa0/1
```

Ez a parancs megmutatja az adott interfész aktuális DTP-állapotát és konfigurációját.

---

## A parancs kimenete (magyarázattal)

```
DTP information for FastEthernet0/1:
  TOS/TAS/TNS:          ACCESS/AUTO/ACCESS
  TOT/TAT/TNT:          NATIVE/NEGOTIATE/NATIVE
  Neighbor address 1:   C80084AEF101
  Neighbor address 2:   000000000000
  Hello timer expiration (sec/state): 11/RUNNING
  Access timer expiration (sec/state): never/STOPPED
  Negotiation timer expiration (sec/state): never/STOPPED
  Multidrop timer expiration (sec/state): never/STOPPED
  FSM state:            S2:ACCESS
  # times multi & trunk: 0
  Enabled:              yes
  In STP:               no
```

---

## A kimenet értelmezése

| Mező | Jelentés |
|---|---|
| `TOS` (Trunk Operational Status) | A port **tényleges** üzemmódja – `ACCESS` = nem trönk |
| `TAS` (Trunk Administrative Status) | A port **konfigurált** üzemmódja – `AUTO` = dynamic auto |
| `TNS` (Trunk Negotiated Status) | Az egyeztetett állapot – `ACCESS` = nem trönkolt |
| `TOT/TAT/TNT` | Beágyazás típusa: `NATIVE` = jelöletlen (native), `NEGOTIATE` = egyeztet |
| `Neighbor address 1` | A szomszédos eszköz MAC-címe |
| `FSM state: S2:ACCESS` | A végállapot: **hozzáférési mód** (nem trönk) |
| `Enabled: yes` | A DTP be van kapcsolva ezen az interfészen |
| `Hello timer: 11/RUNNING` | A DTP rendszeresen küld hello kereteket |

---

## Mikor jelzi a DTP, hogy trönk van?

Ha a port trönk módban van, a kimenet így néz ki:

```
TOS/TAS/TNS:          TRUNK/TRUNK/TRUNK
FSM state:            S3:TRUNK
```

---

## Ellenőrző parancsok összehasonlítása

| Parancs | Mit mutat? |
|---|---|
| `show dtp interface fa0/1` | DTP részletek: mód, szomszéd, időzítők |
| `show interfaces fa0/1 switchport` | Switchport konfiguráció: mód, natív VLAN, engedélyezett VLAN-ok |
| `show interfaces trunk` | Összes aktív trönkinterfész összefoglalója |

---

## Best practice összefoglalás

> **Általános ajánlás:** Ha egy interfészen trönkot akarunk, akkor azt **statikusan** állítsuk be és **kapcsoljuk ki a DTP-t**. Ne hagyatkozzunk az automatikus egyeztetésre.

```
S1(config-if)# switchport mode trunk
S1(config-if)# switchport nonegotiate
```

Azokon az interfészeken, amelyeken nem akarunk trönkot, **kapcsoljuk ki a DTP-t** is:

```
S1(config-if)# switchport mode access
```
