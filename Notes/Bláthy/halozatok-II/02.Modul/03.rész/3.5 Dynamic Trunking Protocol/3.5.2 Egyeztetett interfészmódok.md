# 3.5.2 Egyeztetett interfészmódok

## A switchport mode parancs szintaxisa

```
Switch(config-if)# switchport mode {access | dynamic {auto | desirable} | trunk}
```

---

## Az elérhető módok

| Mód | Parancs | Leírás |
|---|---|---|
| **access** | `switchport mode access` | Állandó hozzáférési mód; soha nem lesz trönk; DTP-t nem küld |
| **dynamic auto** | `switchport mode dynamic auto` | Trönkot hoz létre, ha a szomszéd kéri; **alapértelmezett mód** |
| **dynamic desirable** | `switchport mode dynamic desirable` | Aktívan próbálja kiépíteni a trönkot a szomszéddal |
| **trunk** | `switchport mode trunk` | Állandó trönk mód; mindig trönkként működik |

---

## A módok viselkedése részletesen

### access
- A port **sohasem** lesz trönk
- DTP-kereteket **nem küld és nem fogad el** trönk egyeztetésre
- Csak egyetlen VLAN-t hordoz

### dynamic auto
- Alapértelmezett mód a Catalyst 2960/3650 switch-eken
- **Passzív**: megvárja, amíg a szomszéd trönkot kezdeményez
- Ha a szomszéd is `dynamic auto` → **nem jön létre trönk** (mindkettő vár)

### dynamic desirable
- **Aktív**: maga kezdeményezi a trönk egyeztetést
- Ha a szomszéd `dynamic auto` vagy `dynamic desirable` → **trönk jön létre**

### trunk
- **Állandó trönk**: függetlenül a szomszéd beállításától
- Ha `switchport nonegotiate`-tel kombinálják → DTP-t sem küld

---

## A switchport nonegotiate parancs

```
Switch(config-if)# switchport nonegotiate
```

- Leállítja a DTP-egyeztetést ezen az interfészen
- Csak `access` vagy `trunk` módban alkalmazható
- A szomszédos interfészt manuálisan kell konfigurálni trönkra

> **Mikor használd?** Amikor nem-Cisco eszközhöz csatlakozik a port, vagy amikor biztonsági okokból nem akarod, hogy a switch DTP-kereteket adjon ki.

---

## Példa konfigurációk

**Statikus trönk DTP nélkül (ajánlott):**

```
S1(config-if)# switchport mode trunk
S1(config-if)# switchport nonegotiate
```

**Dinamikus desirable (aktív egyeztetés):**

```
S1(config-if)# switchport mode dynamic desirable
```

**Hozzáférési port (soha nem lesz trönk):**

```
S1(config-if)# switchport mode access
```
