# 8.1.4 Az RA üzenetek három jelzőbitje

## A három jelzőbit (flag)

Az ICMPv6 RA-üzenet 3 jelzőbitet tartalmaz:

| Jelzőbit | Neve | Leírás |
|---|---|---|
| **A** | Address Autoconfiguration flag | SLAAC-kal hozható létre a GUA |
| **O** | Other Configuration flag | Egyéb adatok (DNS, domain) az állapotmentes DHCPv6-tól |
| **M** | Managed Address Configuration flag | Állapottartó DHCPv6-tól kell kérni az egész IPv6-konfigurációt |

---

## A három módszer jelzőbit-kombinációi

### 1. Csak SLAAC (A=1, O=0, M=0)

```
RA: A=1, O=0, M=0
→ Állomás: csak az RA-üzenetet használja
→ Saját GUA: SLAAC-kal (EUI-64 vagy véletlenszerű)
→ DNS, domain: nincs DHCPv6-tól kapva
```

### 2. SLAAC + állapotmentes DHCPv6 (A=1, O=1, M=0)

```
RA: A=1, O=1, M=0
→ Állomás: SLAAC-kal hoz létre GUA-t
→ DNS, domain stb.: állapotmentes DHCPv6-szervertől
```

### 3. Állapottartó DHCPv6 (A=0, O=0, M=1)

```
RA: A=0, O=0, M=1
→ Állomás: állapottartó DHCPv6-szervertől kap mindent
→ Alapértelmezett átjáró: az RA forrás LLA-ja
```

> **Megjegyzés:** Ha A=1 és M=1 egyszerre, egyes OS-ek (pl. Windows) mindkét módszert alkalmazzák – SLAAC-kal is létrehoznak GUA-t, és a DHCPv6-tól is kapnak egyet. Ajánlott az A=0-t kézzel beállítani állapottartó DHCPv6 esetén.
