# 8.4.6 DHCPv6-kiszolgáló ellenőrzésének parancsai

## Ellenőrző parancsok

| Parancs | Mit mutat |
|---|---|
| `show ipv6 dhcp pool` | A DHCPv6-készlet neve, konfigurált adatok, aktív kliensek száma |
| `show ipv6 dhcp binding` | Az összes aktív DHCPv6-bérlet (IPv6 ↔ kliens azonosító leképezés) |

---

## show ipv6 dhcp pool

```
R1# show ipv6 dhcp pool
DHCPv6 pool: IPV6-STATEFUL
  Address allocation prefix: 2001:DB8:ACAD:1::/64
    valid 172800 preferred 86400 (2 in use, 0 conflicts)
  DNS server: 2001:4860:4860::8844
  Domain name: example.com
  Active clients: 2
```

> Az `Active clients: 2` azt jelzi, hogy PC1 és R3 is ebből a szerverből kapták a GUA-jukat.

---

## show ipv6 dhcp binding

```
R1# show ipv6 dhcp binding
Client: FE80::2
  DUID: 0003000100505680ED02
  Username : unassigned
  VRF : default
  IA NA: IA-ID 0x00030001, T1 43200, T2 69120
    Address: 2001:DB8:ACAD:1:IA-NA:...
      preferred lifetime 86400, valid lifetime 172800
```
