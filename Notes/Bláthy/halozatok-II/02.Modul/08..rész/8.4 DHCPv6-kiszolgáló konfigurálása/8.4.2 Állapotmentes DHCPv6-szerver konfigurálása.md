# 8.4.2 Állapotmentes DHCPv6-szerver konfigurálása

## A topológia

```
PC1 ── R1 ── G0/0/1 ── G0/0/1 ── R3
(kliens)   (állapotmentes DHCPv6 szerver)
```

---

## Az 5 konfigurálási lépés

### 1. lépés – IPv6-forgalomirányítás engedélyezése

```
R1(config)# ipv6 unicast-routing
```

### 2. lépés – DHCPv6-készlet neve

```
R1(config)# ipv6 dhcp pool IPV6-STATELESS
R1(config-dhcpv6)#
```

### 3. lépés – Készlet konfigurálása

```
R1(config-dhcpv6)# dns-server 2001:db8:acad:1::254
R1(config-dhcpv6)# domain-name example.com
R1(config-dhcpv6)# exit
```

> Az állapotmentes DHCPv6-készletben **nincs `address prefix`** – az IP-t SLAAC adja.

### 4. lépés – Készlet hozzárendelése az interfészhez

```
R1(config)# interface g0/0/1
R1(config-if)# ipv6 nd other-config-flag
R1(config-if)# ipv6 dhcp server IPV6-STATELESS
R1(config-if)# exit
```

### 5. lépés – Ellenőrzés

```
R1# show ipv6 dhcp pool
DHCPv6 pool: IPV6-STATELESS
  DNS server: 2001:db8:acad:1::254
  Domain name: example.com
  Active clients: 0
```
