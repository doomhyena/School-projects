# 8.4.5 Állapottartó DHCPv6-kliens konfigurálása

## Feladat: R3 mint állapottartó DHCPv6-kliens

Az R3 router kliensként DHCPv6-tól kap mindent (GUA, DNS, domain). A default gatewayt az RA-ból kapja.

---

## Az 5 konfigurálási lépés

### 1. lépés – IPv6-forgalomirányítás engedélyezése

```
R3(config)# ipv6 unicast-routing
```

### 2. lépés – LLA konfigurálása az interfészen

```
R3(config)# interface g0/0/1
R3(config-if)# ipv6 enable
```

### 3. lépés – Állapottartó DHCPv6 kliensként való konfigurálás

```
R3(config-if)# ipv6 address dhcp
```

### 4. lépés – GUA megkapásának ellenőrzése

```
R3# show ipv6 interface g0/0/1
GigabitEthernet0/0/1 is up, line protocol is up
  IPv6 is enabled, link-local address is FE80::2
  Global unicast address(es):
    2001:DB8:ACAD:1:...
    ...DHCPv6 assigned
```

### 5. lépés – DHCPv6-adatok ellenőrzése

```
R3# show ipv6 dhcp interface g0/0/1
GigabitEthernet0/0/1 is in client mode
  ...
  DNS server: 2001:DB8:ACAD:1::254
  Domain name: example.com
```

---

## Összehasonlítás: állapotmentes vs. állapottartó kliens konfig

| | Állapotmentes kliens | Állapottartó kliens |
|---|---|---|
| IP-cím forrása | `ipv6 address autoconfig` (SLAAC) | `ipv6 address dhcp` (DHCPv6) |
| DNS forrása | DHCPv6 | DHCPv6 |
