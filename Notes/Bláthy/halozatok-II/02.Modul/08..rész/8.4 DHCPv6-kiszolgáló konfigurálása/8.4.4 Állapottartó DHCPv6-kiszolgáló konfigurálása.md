# 8.4.4 Állapottartó DHCPv6-kiszolgáló konfigurálása

## A topológia

```
PC1 ── R1 ── G0/0/1 ── G0/0/1 ── R3
(kliens)   (állapottartó DHCPv6 szerver)
```

---

## Az állapottartó DHCPv6-szerver vs. állapotmentes

A legnagyobb különbség: az állapottartó készletben **`address prefix`** paranccsal adunk meg kiosztható IP-tartományt.

---

## Az 5 konfigurálási lépés

### 1. lépés – IPv6-forgalomirányítás engedélyezése

```
R1(config)# ipv6 unicast-routing
```

### 2. lépés – DHCPv6-készlet neve

```
R1(config)# ipv6 dhcp pool IPV6-STATEFUL
R1(config-dhcpv6)#
```

### 3. lépés – Készlet konfigurálása

```
R1(config-dhcpv6)# address prefix 2001:db8:acad:1::/64
R1(config-dhcpv6)# dns-server 2001:db8:acad:1::254
R1(config-dhcpv6)# domain-name example.com
R1(config-dhcpv6)# exit
```

### 4. lépés – Készlet hozzárendelése az interfészhez

```
R1(config)# interface g0/0/1
R1(config-if)# ipv6 nd managed-config-flag
R1(config-if)# ipv6 nd prefix default no-autoconfig
R1(config-if)# ipv6 dhcp server IPV6-STATEFUL
R1(config-if)# exit
```

### 5. lépés – Ellenőrzés

```
R1# show ipv6 dhcp pool
DHCPv6 pool: IPV6-STATEFUL
  Address allocation prefix: 2001:DB8:ACAD:1::/64 valid 172800 preferred 86400 (2 in use, 0 conflicts)
  DNS server: 2001:DB8:ACAD:1::254
  Domain name: example.com
  Active clients: 2
```
