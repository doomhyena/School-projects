# 8.3.5 Állapottartó DHCPv6 engedélyezése interfészen

## A parancsok

```
R1(config)# interface g0/0/1
R1(config-if)# ipv6 nd managed-config-flag
R1(config-if)# ipv6 nd prefix default no-autoconfig
```

| Parancs | Hatás |
|---|---|
| `ipv6 nd managed-config-flag` | M=1: állomásoknak állapottartó DHCPv6-ból kell IP-t kérni |
| `ipv6 nd prefix default no-autoconfig` | A=0: letiltja a SLAAC-ot (ne legyen dupla cím) |

---

## Ellenőrzés

```
R1# show ipv6 interface g0/0/1 | begin ND
  ND DAD is enabled, number of DAD attempts: 1
  ND router advertisements are sent every 200 seconds
  Hosts use DHCP to obtain routable addresses.
```

Az utolsó sor: `Hosts use DHCP to obtain routable addresses.` → az M jelzőbit be van állítva.

---

## Összehasonlítás: állapotmentes vs. állapottartó engedélyezése

| Módszer | Parancs | Jelzőbit változás |
|---|---|---|
| Állapotmentes DHCPv6 | `ipv6 nd other-config-flag` | O=1 |
| Állapottartó DHCPv6 | `ipv6 nd managed-config-flag` + `ipv6 nd prefix default no-autoconfig` | M=1, A=0 |
