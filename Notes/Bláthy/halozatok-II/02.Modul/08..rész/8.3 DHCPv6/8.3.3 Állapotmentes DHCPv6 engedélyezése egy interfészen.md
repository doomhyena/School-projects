# 8.3.3 Állapotmentes DHCPv6 engedélyezése egy interfészen

## A parancs

Az O jelzőbit 1-re állítása:

```
R1(config-if)# ipv6 nd other-config-flag
```

Visszaállítás alapértelmezésre (O=0):

```
R1(config-if)# no ipv6 nd other-config-flag
```

---

## Ellenőrzés

```
R1# show ipv6 interface g0/0/1 | begin ND
  ND DAD is enabled, number of DAD attempts: 1
  ND router advertisements are sent every 200 seconds
  Hosts use stateless autoconfig for addresses.
  Hosts use DHCP to obtain other configuration.
```

Az utolsó sor: `Hosts use DHCP to obtain other configuration.` → az O jelzőbit be van állítva.

---

## Összefoglalás

| Parancs | Hatás |
|---|---|
| `ipv6 nd other-config-flag` | O=1: állomások állapotmentes DHCPv6-tól kérik a DNS stb. adatokat |
| `no ipv6 nd other-config-flag` | O=0: csak SLAAC mód (alapértelmezés) |
