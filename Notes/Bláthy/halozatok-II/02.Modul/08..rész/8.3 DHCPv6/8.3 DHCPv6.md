# 8.3 DHCPv6

A DHCPv6 két változata: állapotmentes (stateless) és állapottartó (stateful) DHCPv6. Mi a különbség, mikor melyiket használjuk, és hogyan engedélyezzük az interfészen?

---

## Fejezetek

| Fejezet | Téma |
|---|---|
| [[8.3.1 A DHCPv6 működésének lépései]] | DHCPv6 üzenetváltás: Solicit → Advertise → Request → Reply |
| [[8.3.2 Az állapotmentes DHCPv6 működése]] | SLAAC adja az IP-t, DHCPv6 csak DNS-t és domain-t |
| [[8.3.3 Állapotmentes DHCPv6 engedélyezése egy interfészen]] | `ipv6 nd other-config-flag` (O bit = 1) |
| [[8.3.4 Az állapottartó DHCPv6 működése]] | Teljes konfiguráció DHCPv6-tól (mint DHCPv4) |
| [[8.3.5 Állapottartó DHCPv6 engedélyezése interfészen]] | `ipv6 nd managed-config-flag` (M bit = 1) |
