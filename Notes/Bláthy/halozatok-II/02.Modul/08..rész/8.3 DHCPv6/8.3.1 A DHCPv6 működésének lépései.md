# 8.3.1 A DHCPv6 működésének lépései

## DHCPv6 vs DHCPv4

A DHCPv6 a kínált szolgáltatások tekintetében hasonlít a DHCPv4-hez, de a két protokoll **egymástól teljesen független**. (RFC 3315)

---

## DHCPv6 UDP portok

| Irány | Port |
|---|---|
| Szerver → kliens | **546** (cél) |
| Kliens → szerver | **547** (cél) |

---

## A DHCPv6 működés 6 lépése

```
Állomás (kliens)                        DHCPv6 szerver
     │──── 1. RS ─────────────────►  Router
     │◄─── 2. RA (O=1 vagy M=1) ──  Router  ← RA jelzi, hogy DHCPv6 szükséges
     │──── 3. SOLICIT (ff02::1:2) ──────────────────────►│
     │◄─── 4. ADVERTISE ──────────────────────────────── │
     │──── 5. REQUEST / INFORMATION-REQUEST ─────────────►│
     │◄─── 6. REPLY ──────────────────────────────────── │
```

| Lépés | Üzenet | Leírás |
|---|---|---|
| 1 | RS | Állomás routert keres |
| 2 | RA | Router válaszol (O=1 vagy M=1 jelzőbittel) |
| 3 | SOLICIT | Állomás DHCPv6-szervert keres |
| 4 | ADVERTISE | DHCPv6-szerver ajánl |
| 5 | REQUEST / INFO-REQ | Állomás kéri az adatokat |
| 6 | REPLY | DHCPv6-szerver megerősít |
