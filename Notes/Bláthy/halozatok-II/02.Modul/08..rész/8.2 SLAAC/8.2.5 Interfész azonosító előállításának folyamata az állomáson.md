# 8.2.5 Interfész-azonosító előállításának folyamata az állomáson

## A 128 bites IPv6 GUA felépítése SLAAC esetén

```
│←─────── 64 bit előtag (RA-ból) ──────────→│←──── 64 bit interfész-azonosító ─────→│
 2001:db8:acad:1      :     :     :     :     1de9 : 0c69 : 73ee : ca8c
 (az RA-üzenetből)                            (állomás saját maga generálja)
```

---

## Az interfész-azonosító két generálási módszere

| Módszer | Leírás | Ki használja? |
|---|---|---|
| **Véletlenszerű generálás** | 64 bites véletlen szám | Windows 10 (adatvédelmi okból) |
| **EUI-64** | MAC-cím-alapú: 48 bites MAC → 64 bit (fffe beillesztése + 7. bit invertálása) | Egyes régebbi OS-ek, Cisco IOS |

---

## Az EUI-64 módszer lépései

```
1. MAC-cím:         00:50:56:B3:ED:05
2. Két részre osztás: 0050:56  |  B3:ED:05
3. FFFE beillesztése közé: 0050:56FF:FEB3:ED05
4. 7. bit invertálása:     0250:56FF:FEB3:ED05
   (00 → 02, mert bit7 = 0 → 1)
```

> **Adatvédelmi szempont:** Az EUI-64 azonosítható a MAC-cím alapján → ezért a legtöbb modern OS véletlenszerű módszert használ.
