# 7.3.1 A Cisco Router, mint DHCPv4-kliens

## Mikor szükséges router mint DHCP-kliens?

Vannak esetek, amikor a Cisco routert **nem szerverként, hanem kliensként** kell beállítani:
- Otthoni és kisvállalati hálózatban (SOHO), ahol az **ISP ad DHCP-t**
- Fiókirodai routerek, amelyek az ISP-től kapnak IP-t a WAN-interfészen

---

## A konfiguráció

Az Ethernet-interfész DHCP-kliensként beállítható az `ip address dhcp` paranccsal:

```
SOHO(config)# interface GigabitEthernet 0/0/1
SOHO(config-if)# ip address dhcp
SOHO(config-if)# no shutdown
```

A sikerről naplóüzenet tájékoztat:

```
%DHCP-6-ADDRESS_ASSIGN: Interface GigabitEthernet0/0/1 assigned DHCP address 
209.165.201.12, mask 255.255.255.224, hostname SOHO
```

---

## Ellenőrzés

```
SOHO# show ip interface g0/0/1
GigabitEthernet0/0/1 is up, line protocol is up
  Internet address is 209.165.201.12/27
  Broadcast address is 255.255.255.255
  Address determined by DHCP
```
