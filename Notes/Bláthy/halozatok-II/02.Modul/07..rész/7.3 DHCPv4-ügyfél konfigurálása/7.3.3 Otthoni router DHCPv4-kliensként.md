# 7.3.3 Otthoni router DHCPv4-kliensként

## Alapértelmezett beállítás

Az otthoni (fogyasztói) routerek WAN-portja alapértelmezés szerint **DHCPv4-kliensként** van beállítva. Ez lehetővé teszi, hogy az ISP-hez csatlakozáskor automatikusan kapjanak IP-t – a felhasználónak semmit sem kell konfigurálni.

---

## A Packet Tracer wireless router beállítása

A Cisco Packet Tracerben a vezeték nélküli router **Internet** (WAN) portjának alapértelmezett beállítása:

```
Internet Connection Type: Automatic Configuration – DHCP
```

Ez azt jelenti:
- Ha DSL- vagy kábelmodemet csatlakoztatunk → az ISP-től kap IPv4-t DHCP-n keresztül
- Automatikusan megkapja: IP, alhálózati maszk, átjáró, DNS

---

## Összehasonlítás: Cisco IOS vs. otthoni router

| | Cisco IOS router | Otthoni fogyasztói router |
|---|---|---|
| DHCPv4-kliens parancsa | `ip address dhcp` az interfészen | Grafikus felületen: DHCP kiválasztása |
| Ellenőrzés | `show ip interface G0/0/1` | Webfelület státuszoldala |
