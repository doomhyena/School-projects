# 7.3.4 Parancsszimulátor – Cisco router konfigurálása DHCP-ügyfélként

## A feladat

A SOHO routert konfigurálod DHCPv4-kliensként, hogy az ISP-től kapjon IP-t a G0/0/1 interfészen.

---

## Lépések és parancsok

### 1. lépés – Interfész konfigurációs módba

```
SOHO(config)# interface g0/0/1
```

### 2. lépés – IP-cím DHCP-ről

```
SOHO(config-if)# ip address dhcp
```

### 3. lépés – Interfész aktiválása

```
SOHO(config-if)# no shutdown
```

Naplóüzenet a sikeres kiosztásról:

```
Sep 12 10:01:25.773: %DHCP-6-ADDRESS_ASSIGN: Interface GigabitEthernet0/0/1 
assigned DHCP address 209.165.201.12, mask 255.255.255.224, hostname SOHO
```

### 4. lépés – Visszatérés privileged EXEC módba

```
SOHO(config-if)# end
```

### 5. lépés – Ellenőrzés

```
SOHO# show ip interface g0/0/1
GigabitEthernet0/0/1 is up, line protocol is up
  Internet address is 209.165.201.12/27
  Broadcast address is 255.255.255.255
  Address determined by DHCP
(output omitted)
```
