# 7.2.8 DHCPv4 Relay

## A probléma

Hierarchikus vállalati hálózatokban a **DHCP-szerver más hálózaton** van, mint a kliensek. Mivel a router alapértelmezés szerint **nem továbbítja a szórási csomagokat** alhálózatok között, a kliensek nem érik el a DHCP-szervert.

```
PC1 ──── S1 ──── R1 ──────── S2 ──── DHCP szerver
192.168.10.0/24      G0/0/0  G0/0/1  192.168.11.6/24

PC1 küld DHCPDISCOVER szórást → R1 megállítja, nem továbbítja!
```

---

## A megoldás: ip helper-address

Az R1-et **DHCP-közvetítővé (relay agent)** konfiguráljuk az `ip helper-address` paranccsal:

```
R1(config)# interface GigabitEthernet 0/0/0
R1(config-if)# ip helper-address 192.168.11.6
```

Ezután az R1 a PC1-től érkező DHCP szórásokat **unicastként** továbbítja a megadott DHCP-szerver felé.

---

## A relay agent folyamata

```
1. PC1 küld: DHCPDISCOVER (szórás 255.255.255.255)
2. R1 fogja és unicastként továbbítja → 192.168.11.6 (DHCP szerver)
3. DHCP szerver antwortet → R1 → PC1
```

---

## Ellenőrzés

```
R1# show ip interface GigabitEthernet 0/0/0
...
Helper address is 192.168.11.6
```
