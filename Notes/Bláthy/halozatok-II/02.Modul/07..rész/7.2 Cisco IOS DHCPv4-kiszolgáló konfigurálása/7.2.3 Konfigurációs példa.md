# 7.2.3 Konfigurációs példa

## A topológia

```
PC1 ── S1 ── R1 ── S2 ── PC2
        G0/0/0      G0/0/1
     192.168.10.0/24    192.168.11.0/24
           .1                  .1
                     DNS: 192.168.11.5/24
```

Az R1-et DHCPv4-kiszolgálóként konfiguráljuk a **192.168.10.0/24** hálózat számára.

---

## Teljes konfiguráció

```
R1(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.9
R1(config)# ip dhcp excluded-address 192.168.10.254
R1(config)# ip dhcp pool LAN-POOL-1
R1(dhcp-config)# network 192.168.10.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.10.1
R1(dhcp-config)# dns-server 192.168.11.5
R1(dhcp-config)# domain-name example.com
R1(dhcp-config)# end
R1#
```

---

## Mit jelent ez?

- A `.1` – `.9` tartomány kizárva (router és szerverek statikus IP-nek)
- A `.254` kizárva (pl. broadcast management cím)
- A kliensek a `.10` – `.253` tartományból kapnak IP-t
- Alapértelmezett átjáró: `192.168.10.1`
- DNS-szerver: `192.168.11.5`
- Domain: `example.com`
