# 7.2.9 Egyéb továbbított szórásos szolgáltatások

## Az ip helper-address 8 UDP-szolgáltatást továbbít

Az `ip helper-address` parancs nem csak a DHCP-forgalmat közvetíti. Alapértelmezés szerint **8 UDP-alapú szolgáltatást** továbbít:

| UDP port | Szolgáltatás |
|---|---|
| **37** | Time (időszinkronizáció) |
| **49** | TACACS (terminál hozzáférés vezérlés) |
| **53** | DNS |
| **67** | DHCP/BOOTP-kiszolgáló |
| **68** | DHCP/BOOTP-kliens |
| **69** | TFTP |
| **137** | NetBIOS névszolgáltatás |
| **138** | NetBIOS datagram szolgáltatás |
