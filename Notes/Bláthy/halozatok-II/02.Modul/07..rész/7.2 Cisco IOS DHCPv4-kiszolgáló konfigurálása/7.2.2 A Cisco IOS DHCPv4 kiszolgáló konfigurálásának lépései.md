# 7.2.2 A Cisco IOS DHCPv4-kiszolgáló konfigurálásának lépései

## 3 lépéses konfigurálás

### 1. lépés – Kizárt IP-k megadása

A DHCP-szerver alapértelmezés szerint a készlet összes IP-jét kiadja. Kizárjuk azokat, amelyek statikusan vannak kiosztva (routereknek, szervereknek stb.):

```
R1(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.9
R1(config)# ip dhcp excluded-address 192.168.10.254
```

### 2. lépés – Készlet (pool) neve

```
R1(config)# ip dhcp pool LAN-POOL-1
R1(dhcp-config)#
```

A `ip dhcp pool` parancs DHCPv4 konfigurációs módba lép (`dhcp-config#` prompt).

### 3. lépés – Készlet konfigurálása

| Parancs | Leírás | Kötelező? |
|---|---|---|
| `network 192.168.10.0 255.255.255.0` | Kiosztható IP-tartomány | ✅ Igen |
| `default-router 192.168.10.1` | Alapértelmezett átjáró | ✅ Igen |
| `dns-server 192.168.11.5` | DNS-szerver IP-je | Nem |
| `domain-name example.com` | Domain név | Nem |
| `lease 7` | Bérleti idő napokban (alap: 1 nap) | Nem |
| `netbios-name-server IP` | NetBIOS WINS-szerver | Nem |

> **Megjegyzés:** A Microsoft nem javasolja a WINS használatát – inkább DNS-t használjunk.
