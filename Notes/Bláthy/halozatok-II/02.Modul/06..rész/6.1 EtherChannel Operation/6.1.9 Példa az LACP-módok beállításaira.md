# 6.1.9 Példa az LACP-módok beállításaira

## A topológia

```
S1 (Fa0/1, Fa0/2) ═══ S2 (Fa0/1, Fa0/2)
```

---

## LACP módkombinációk összefoglalása

| S1 módja | S2 módja | Eredmény |
|---|---|---|
| active | active | ✅ EtherChannel létrejön |
| active | passive | ✅ EtherChannel létrejön |
| passive | active | ✅ EtherChannel létrejön |
| passive | passive | ❌ Nem jön létre |
| on | on | ✅ EtherChannel létrejön (egyeztetés nélkül) |

---

## Konfigurációs példa – `channel-group` módlehetőségek

A `?` operátorral megjeleníthetők a lehetséges módok:

```
S1(config-if-range)# channel-group 1 mode ?
  active     Enable LACP unconditionally
  auto       Enable PAgP only if a PAgP device is detected
  desirable  Enable PAgP unconditionally
  on         Enable EtherChannel only
  passive    Enable LACP only if a LACP device is detected
```
