# 6.2.3 Parancsszimulátor – Az EtherChannel konfigurálása

## A feladat

Konfiguráld az EtherChannel-t S1-en a következő követelmények alapján:

**Topológia:** S1 Fa0/1 és Fa0/2 portjai → S2 Fa0/1 és Fa0/2 portjaihoz csatlakoznak.

---

## Lépések és parancsok

### 1. lépés – Interface range mód megnyitása

```
S1(config)# interface range fa 0/1 - 2
```

### 2. lépés – channel-group konfigurálása (LACP active)

```
S1(config-if-range)# channel-group 1 mode active
```

A lehetséges módok:
```
S1(config-if-range)# channel-group 1 mode ?
  active     Enable LACP unconditionally
  auto       Enable PAgP only if a PAgP device is detected
  desirable  Enable PAgP unconditionally
  on         Enable Etherchannel only
  passive    Enable LACP only if a LACP device is detected
```

### 3. lépés – Portcsatorna interfész konfigurálása

```
S1(config)# interface port-channel 1
S1(config-if)# switchport mode trunk
S1(config-if)# switchport trunk allowed vlan 1,2,20
```

---

## Sikeres konfiguráció visszajelzés

```
You have successfully configured EtherChannel.
```
