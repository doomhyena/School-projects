# 6.2.2 LACP konfigurációs példa

## A topológia

```
S1 (Fa0/1, Fa0/2) ═══ S2 (Fa0/1, Fa0/2)
```

Az S1 és S2 között LACP-alapú EtherChannel jön létre.

---

## S1 konfigurációja (LACP active)

```
S1(config)# interface range FastEthernet 0/1 - 2
S1(config-if-range)# channel-group 1 mode active
Creating a port-channel interface Port-channel 1
S1(config-if-range)# exit
S1(config)# interface port-channel 1
S1(config-if)# switchport mode trunk
S1(config-if)# switchport trunk allowed vlan 1,2,20
```

---

## S2 konfigurációja (LACP active vagy passive)

```
S2(config)# interface range FastEthernet 0/1 - 2
S2(config-if-range)# channel-group 1 mode active
S2(config-if-range)# exit
S2(config)# interface port-channel 1
S2(config-if)# switchport mode trunk
S2(config-if)# switchport trunk allowed vlan 1,2,20
```

> **Megjegyzés:** S2-n passive mód is működne, mert S1 active módban van. De az active + active kombináció az ajánlott, mert mindkét oldal aktívan egyeztet.

---

## Mi történik konfigurálás közben?

Az EtherChannel létrehozásakor a portok átmenetileg le-fel kapcsolgatnak:

```
*Mar 21 00:02:28.184: %LINEPROTO-5-UPDOWN: Line protocol on Interface FastEthernet0/1, changed state to down
*Mar 21 00:04:34.114: %LINK-3-UPDOWN: Interface Port-channel1, changed state to up
```
