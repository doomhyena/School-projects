# 6.3.3 EtherChannel hibaelhárítási példa

## A szituáció

S1 és S2 switch-ek F0/1 és F0/2 portjain EtherChannel van konfigurálva, de **nem működik**.

---

## 1. lépés – Az EtherChannel állapotának ellenőrzése

```
S1# show etherchannel summary
...
Group  Port-channel  Protocol    Ports
------+-------------+-----------+--------------------
1      Po1(SD)       -           Fa0/1(D)    Fa0/2(D)
```

**Jelzők értelmezése:**
- `SD` = Layer2, **Down** → a portcsatorna nem működik
- `D` = portok **le vannak választva** a csatornáról

---

## 2. lépés – A portcsatorna konfigurációjának vizsgálata

```
S1# show etherchannel port-channel
...
```

Megvizsgáljuk a trönkbeállítást és az engedélyezett VLAN-okat.

---

## 3. lépés – A hiba megtalálása és javítása

Ha például az S1 portcsatornáján a native VLAN eltér az S2-étől:

```
S1(config)# interface port-channel 1
S1(config-if)# switchport trunk native vlan 1
```

Ha a VLAN-ok eltérnek:

```
S1(config-if)# switchport trunk allowed vlan 1,2,20
```

---

## 4. lépés – Az EtherChannel működésének ellenőrzése

```
S1# show etherchannel summary
...
1      Po1(SU)       LACP        Fa0/1(P)    Fa0/2(P)
```

Az `SU` és `P` jelzők azt mutatják, hogy az EtherChannel mostantól **működik**.

---

## Összefoglalás: hibakeresési lépések

1. `show etherchannel summary` → csatorna állapota (SU=OK, SD=hiba)
2. `show etherchannel port-channel` → részletes konfig vizsgálata
3. `show running-config interface port-channel X` → eltérések keresése
4. Javítás a portcsatorna interfészen → `show etherchannel summary` ismét
