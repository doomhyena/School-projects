# 6.3.1 Az EtherChannel ellenőrzése

## Ellenőrző parancsok

| Parancs | Mit mutat |
|---|---|
| `show interfaces port-channel 1` | A portcsatorna interfész általános állapota (up/down, BW) |
| `show etherchannel summary` | Összefoglaló: csatorna állapota, protokoll, tagportok |
| `show etherchannel port-channel` | Részletes információ a portcsatornáról (LACPdu, PAgP stb.) |
| `show interfaces etherchannel` | Az egyes fizikai portok EtherChannel-specifikus adatai |

---

## show interfaces port-channel 1

```
S1# show interfaces port-channel 1
Port-channel1 is up, line protocol is up (connected)
  Hardware is EtherChannel, address is c07b.bcc4.a981
  MTU 1500 bytes, BW 200000 Kbit/sec, DLY 100 usec,
     reliability 255/255, txload 1/255, rxload 1/255
(output omitted)
```

> BW 200000 Kbit/sec = 2 × 100Mbps = 200Mbps (két összefogott Fast Ethernet port)

---

## show etherchannel summary

```
S1# show etherchannel summary
Flags: D - down  P - bundled in port-channel
       I - stand-alone  s - suspended
       H - Hot-standby (LACP only)
       R - Layer3  S - Layer2
       U - in use  N - not in use, no aggregation
       f - failed to allocate aggregator
       ...

Group  Port-channel  Protocol    Ports
------+-------------+-----------+-----------------------------------------------
1      Po1(SU)       LACP        Fa0/1(P)    Fa0/2(P)
```

**Állapotjelzők értelmezése:**
- `SU` = Layer2, in use (működő)
- `P` = port kötegbe csatlakoztatva
- `SD` = Layer2, down (nem működő!)
- `D` = port le van választva
