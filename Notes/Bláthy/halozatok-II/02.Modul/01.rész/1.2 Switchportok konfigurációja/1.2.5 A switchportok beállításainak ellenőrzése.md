# 1.2.5 A switchportok beállításainak ellenőrzése

## A show running-config ellenőrzése

A `show running-config` paranccsal meggyőződhetünk arról, hogy a switch beállításai helyesek-e. Az alábbi részlet a legfontosabb felügyeleti adatokat mutatja:

```
S1# show running-config
...
interface FastEthernet0/18
 switchport access vlan 99
...
interface vlan 99
 ip address 172.17.99.11 255.255.255.0
...
ip default-gateway 172.17.99.1
```

**Mit ellenőrzünk?**
- Az Fa0/18 port a 99-es felügyeleti VLAN-hoz van rendelve ✓
- A VLAN 99 interfész a `172.17.99.11/24` IPv4-címmel van konfigurálva ✓
- Az alapértelmezett átjáró a `172.17.99.1` ✓

---

## A show interfaces parancs

A `show interfaces` parancs részletes állapotot és statisztikákat jelenít meg:

```
S1# show interfaces fastEthernet 0/18
FastEthernet0/18 is up, line protocol is up (connected)
  Hardware is Fast Ethernet, ...
  Full-duplex, 100Mb/s, ...
```

**Az első két sor értelmezése:**

| Kifejezés | Mit jelent? |
|---|---|
| `FastEthernet0/18 is up` | A fizikai réteg rendben van (kábel csatlakoztatva) |
| `line protocol is up` | Az adatkapcsolati réteg működik (keepalive-ok fogadva) |
| `Full-duplex, 100Mb/s` | A sebesség és duplexitás beállítása |

---

## Lehetséges állapotok és okaik

| Állapot | Jelentés | Lehetséges ok |
|---|---|---|
| `up/up` | Minden rendben | – |
| `up/down` | 2. rétegi hiba | Eltérő beágyazás, error-disabled, hardver |
| `down/down` | Fizikai probléma | Kábel nem csatlakoztatva |
| `administratively down` | Manuálisan letiltva | `shutdown` parancsot adtak ki |
