# 1.2.4 A switch ellenőrzésére szolgáló parancsok

## A legfontosabb show parancsok

Az alábbi parancsok nélkülözhetetlenek a switch állapotának ellenőrzésekor és a hibaelhárítás során:

| Feladat | IOS parancs |
|---|---|
| Interfész állapota és konfigurációja | `show interfaces [interface-id]` |
| Az érvényes indítási konfiguráció | `show startup-config` |
| Az érvényes aktív konfiguráció | `show running-config` |
| Flash fájlrendszer információi | `show flash` |
| Rendszer hardver- és szoftverállapot | `show version` |
| Parancselőzmények | `show history` |
| Interfész IPv4 beállításai | `show ip interface [interface-id]` |
| Interfész IPv6 beállításai | `show ipv6 interface [interface-id]` |
| MAC-címtábla | `show mac-address-table` vagy `show mac address-table` |

---

## A leggyakrabban használt parancsok részletesen

### `show interfaces`
Megmutatja az interfész fizikai és logikai állapotát, a sebesség- és duplexbeállítást, valamint a hibaszámlálókat (pl. ütközések, CRC-hibák).

```
S1# show interfaces FastEthernet 0/18
FastEthernet0/18 is up, line protocol is up (connected)
  Hardware is Fast Ethernet, address is ...
  Full-duplex, 100Mb/s, media type is 10/100BaseTX
  ...
```

### `show running-config`
Az aktuálisan futó konfigurációt mutatja. Hibaelhárításnál az első lépés.

### `show version`
A switch modelljét, az IOS verziót, a szoftver nevét (benne a „k9" = kriptográfiai képesség), a flash és RAM méretét mutatja.

### `show mac address-table`
Megmutatja a switch MAC-címtáblájának tartalmát – melyik MAC-cím melyik porton érhető el.
