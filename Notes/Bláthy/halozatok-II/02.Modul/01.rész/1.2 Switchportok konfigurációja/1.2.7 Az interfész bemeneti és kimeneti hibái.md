# 1.2.7 Az interfész bemeneti és kimeneti hibái

## Bemeneti hibák (Input errors)

A **bemeneti hibák** számlálója az összes hibás, beérkező csomagot összesíti. Az egyes hibatípusok részletes okait az alábbi táblázat tartalmazza:

| Hibatípus | Leírás | Lehetséges ok |
|---|---|---|
| **Runts** | 64 byte-nál rövidebb keret (az Ethernet minimum mérete) | Hibás hálózati kártya, sok ütközés félduplex módban |
| **Giants** | A maximálisan engedélyezett méretnél (1518 byte) nagyobb keret | Hibás hálózati kártya, konfigurációs hiba |
| **CRC errors** | A keret ellenőrző összege nem stimmel | Elektromos interferencia, laza/sérült csatlakozó, rossz kábel |

> **Ha sok CRC-hibát tapasztalsz:** Vizsgáld meg a kábelt és keress közelben elektromos zajforrásokat (pl. motoros eszközök, mikrohullámú sütő, más kábelek).

---

## Kimeneti hibák (Output errors)

A **kimeneti hibák** számlálója azokat a hibákat összesíti, amelyek megakadályozták a keretek elküldését:

| Hibatípus | Leírás | Lehetséges ok |
|---|---|---|
| **Collisions** | Ütközések (félduplex módban normális jelenség) | Félduplex mód + több eszköz osztozik a közegen |
| **Late collisions** | Ütközés a keret 512 bitje után | Túl hosszú kábel, duplexitás-eltérés (one side full, other half) |

> **Késői ütközések (Late collisions) = komoly probléma!**
> Helyes hálózatban nem fordulhatnak elő. Ha látod:
> 1. Ellenőrizd a kábelhosszt (max ~100m UTP esetén)
> 2. Ellenőrizd a duplexitás beállítást mindkét oldalon – a fél-duplexes oldalon jelennek meg a késői ütközések

## Hogyan nézi meg ezeket a show interfaces kimenetből?

```
S1# show interfaces FastEthernet 0/1
...
     5 minute input rate 0 bits/sec, 0 packets/sec
     5 minute output rate 0 bits/sec, 0 packets/sec
        0 input errors, 0 runts, 0 giants, 0 throttles
        0 CRC, 0 frame, 0 overrun, 0 ignored
        0 output errors, 0 collisions, 0 interface resets
        0 late collision, 0 deferred
```

A nulláktól eltérő értékek jelzik, hogy valamilyen probléma van.
