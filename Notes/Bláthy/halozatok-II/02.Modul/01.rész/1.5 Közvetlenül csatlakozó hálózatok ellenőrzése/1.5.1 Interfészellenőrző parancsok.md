# 1.5.1 Interfészellenőrző parancsok

## Miért ellenőrizzük az interfészeket?

Egy router konfigurálása után **mindig ellenőrizzük** a beállításokat és a kapcsolatokat. Az ellenőrző parancsok segítségével gyorsan megállapíthatjuk, hogy az interfészek aktívak-e, és hogy a konfiguráció helyes-e.

---

## A legfontosabb interfész-ellenőrző parancsok

| Parancs | Mit mutat? |
|---|---|
| `show ip interface brief` | Az összes interfész összefoglalója: IP-cím, állapot (IPv4) |
| `show ipv6 interface brief` | Az összes interfész összefoglalója: IPv6-cím, állapot |
| `show running-config interface [id]` | Egy adott interfészre kiadott parancsok |
| `show ip route` | Az IPv4 útválasztási tábla |
| `show ipv6 route` | Az IPv6 útválasztási tábla |
| `show interfaces` | Részletes állapot és statisztikák |
| `show ip interface` | IPv4-hez kapcsolódó részletek |
| `show ipv6 interface` | IPv6-hoz kapcsolódó részletek |

---

## Gyors állapot-ellenőrzés

A leggyakrabban használt parancs:

```
R1# show ip interface brief
Interface              IP-Address      OK? Method Status    Protocol
GigabitEthernet0/0/0   192.168.10.1    YES manual up        up
GigabitEthernet0/0/1   192.168.11.1    YES manual up        up
Serial0/1/0            209.165.200.225 YES manual up        up
Serial0/1/1            unassigned      YES unset  admin down down
```

**Értelmezés:**
- `Status: up` + `Protocol: up` → Az interfész működik ✓
- `administratively down` → Manuálisan le van tiltva (`shutdown` parancs)
