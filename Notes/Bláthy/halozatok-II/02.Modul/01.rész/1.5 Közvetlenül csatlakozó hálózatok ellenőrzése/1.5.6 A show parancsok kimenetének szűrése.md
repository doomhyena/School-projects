# 1.5.6 A show parancsok kimenetének szűrése

## A probléma: túl sok kimenet

A `show` parancsok olykor **több képernyőnyi adatot** jelenítenek meg. Az alapértelmezett 24 soros lapozásnál a `--More--` jelzésnél meg kell nyomni az Enter vagy Szóköz billentyűt. Ez lassítja a munkát.

**Megoldás:** Szűrők (`|` pipe karakter) és a `terminal length 0` parancs.

---

## A terminal length parancs

```
R1# terminal length 0
```
Ha nulla értéket adunk meg, a router **nem állítja meg** a kimenet futtatását – az összes sor egyszerre jelenik meg.

---

## A pipe (`|`) szűrési parancsok

A `|` karakter után egy szűrési paramétert és egy kifejezést adunk meg.

### section – Egy teljes szekció megjelenítése

Megmutatja azt a teljes részt, amelynek fejléce tartalmazza a kifejezést:

```
R1# show running-config | section line vty
line vty 0 4
 password 7 110A1016141D
 login
 transport input all
```

---

### include – Csak az egyező sorok

Csak azokat a sorokat mutatja, amelyek tartalmazzák a kifejezést:

```
R1# show ip interface brief | include GigabitEthernet
GigabitEthernet0/0/0   192.168.10.1    YES manual up    up
GigabitEthernet0/0/1   192.168.11.1    YES manual up    up
```

---

### exclude – Az egyező sorok kizárása

Minden sort megmutat, kivéve azokat, amelyek tartalmazzák a kifejezést:

```
R1# show ip interface brief | exclude unassigned
Interface              IP-Address      OK? Method Status   Protocol
GigabitEthernet0/0/0   192.168.10.1    YES manual up       up
```

---

### begin – Egy ponttól kezdve

Az első egyező sortól kezdve mutatja a többi sort:

```
R1# show ip route | begin Gateway
Gateway of last resort is not set
      192.168.10.0/24 is variably subnetted, 2 subnets, 2 masks
C        192.168.10.0/24 is directly connected, GigabitEthernet0/0/0
...
```

---

## Összefoglalás

| Szűrő | Hatás |
|---|---|
| `section [kifejezés]` | Az adott fejlécű szekció teljes tartalma |
| `include [kifejezés]` | Csak az egyező sorok |
| `exclude [kifejezés]` | Az egyező sorok kizárva |
| `begin [kifejezés]` | Az egyező sortól az összes többi |
