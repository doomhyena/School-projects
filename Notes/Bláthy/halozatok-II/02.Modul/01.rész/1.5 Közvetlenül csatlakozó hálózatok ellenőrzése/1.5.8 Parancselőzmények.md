# 1.5.8 Parancselőzmények

## Mi az a parancselőzmény?

A **parancselőzmény** (command history) funkció ideiglenesen tárolja a korábban begépelt parancsokat, és lehetővé teszi ezek gyors előhívását – nem kell mindent újra begépelni.

---

## Navigáció a parancselőzményekben

| Billentyű | Hatás |
|---|---|
| `↑` (Fel nyíl) vagy `Ctrl+P` | Előző parancs (egyre régebbiek felé) |
| `↓` (Le nyíl) vagy `Ctrl+N` | Következő parancs (egyre újabbak felé) |

---

## Az előzménypuffer mérete

- **Alapértelmezés:** az utolsó **10** parancsot tárolja
- A méret megváltoztatható az aktuális munkamenetben

### Az előzménypuffer méretének növelése

```
R1# terminal history size 200
```

Ez az aktuális munkamenetben 200 parancsra növeli a puffert.

---

## A parancselőzmények megjelenítése

```
R1# show history
  show ip int brief
  show interface g0/0/0
  show ip route
  show running-config
  show history
  terminal history size 200
```

---

## Példa – terminal history size és show history

```
R1# terminal history size 200
R1# show history
  show ip int brief
  show interface g0/0/0
  show ip route
  show running-config
  show history
  terminal history size 200
```
