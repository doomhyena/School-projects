# 1.5.7 Parancsszimulátor – A show parancsok kimenetének szűrése

## Feladat

Ebben a parancsszimulátoros feladatban a `show` parancsok kimenetét kell szűrni.

---

## Megoldás

### 1. A 'line con' szekció szűrése

```
R1# show running-config | section line con
line con 0
 password 7 05080F1C2243
 transport input none
```

### 2. `down` állapotú interfészek keresése

```
R1# show ip interface brief | include down
Serial0/1/1   unassigned   NO  unset  down  down
```

### 3. `up` állapotú interfészek kizárása

```
R1# show ip interface brief | exclude up
Interface            IP-Address      OK? Method Status    Protocol
Serial0/1/1          unassigned      NO  unset  down      down
```

### 4. Kimenet a 'line' szótól kezdve

```
R1# show running-config | begin line
line con 0
 password 7 05080F1C2243
 transport input none
line vty 0 4
 password 7 110A1016141D
 login
 transport input all
```
