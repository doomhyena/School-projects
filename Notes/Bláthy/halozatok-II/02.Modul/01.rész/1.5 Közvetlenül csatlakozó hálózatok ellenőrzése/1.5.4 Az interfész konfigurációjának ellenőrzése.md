A **show running-config interface** parancs kimenete a megadott interfészre kiadott aktuális parancsokat jeleníti meg az ábrának megfelelően.

```
R1 show running-config interface gigabitethernet 0/0/0Building configuration...Current configuration : 158 bytes!interface GigabitEthernet0/0/0    description Link to LAN 1    ip address 192.168.10.1 255.255.255.0    negotiation auto    ipv6 address 2001:DB8:ACAD:1::1/64endR1#
```

A következő két parancs segítségével részletesebb információt kaphatunk az interfészről:

- **show interfaces**- Az eszköz valamennyi interfészére vonatkozóan jelenít meg információkat és adatforgalmi számlálókat.
- **show ip interface** and **és show ipv6 interface** - Megjelenítik az IPv4-hez és IPv6-hoz kapcsolódó információkat a router összes interfészére vonatkozóan
