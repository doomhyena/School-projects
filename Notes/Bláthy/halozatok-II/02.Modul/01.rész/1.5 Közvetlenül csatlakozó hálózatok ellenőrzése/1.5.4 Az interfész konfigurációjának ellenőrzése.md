# 1.5.4 Az interfész konfigurációjának ellenőrzése

## A show running-config interface parancs

Egy adott interfész **jelenlegi konfigurációs parancsait** a `show running-config interface` paranccsal nézzük meg:

```
R1# show running-config interface gigabitethernet 0/0/0
Building configuration...
Current configuration : 158 bytes
!
interface GigabitEthernet0/0/0
 description Link to LAN 1
 ip address 192.168.10.1 255.255.255.0
 negotiation auto
 ipv6 address 2001:DB8:ACAD:1::1/64
end
```

Ez pontosan azt mutatja, ahogyan az interfész konfigurálva van az aktív konfigurációban.

---

## Részletesebb interfész-ellenőrzés

A `show interfaces` parancs az interfész **minden részletét és statisztikáit** megmutatja:

```
R1# show interfaces GigabitEthernet 0/0/0
GigabitEthernet0/0/0 is up, line protocol is up
  Hardware is ISR4000 with 3 Gigabit Ethernet interfaces
  Description: Link to LAN 1
  Internet address is 192.168.10.1/24
  MTU 1500 bytes, BW 1000000 Kbit/sec
  Full Duplex, 1000Mbps, ...
  ...
```

---

## A három leghasznosabb részletes parancs

| Parancs | Mire jó? |
|---|---|
| `show interfaces` | Összes interfész statisztikái és hibaszámlálói |
| `show ip interface` | IPv4 információk az összes interfészről |
| `show ipv6 interface` | IPv6 információk az összes interfészről |
