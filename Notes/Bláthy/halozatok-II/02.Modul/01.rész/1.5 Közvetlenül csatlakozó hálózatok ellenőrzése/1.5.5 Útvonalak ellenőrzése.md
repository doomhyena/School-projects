# 1.5.5 Útvonalak ellenőrzése

## Az útválasztási tábla

Az útválasztási tábla megmutatja, hogy a router **melyik hálózatokat ismeri** és hogyan éri el őket. A közvetlenül csatlakoztatott interfészek automatikusan bekerülnek ebbe a táblába.

---

## IPv4 útválasztási tábla ellenőrzése

```
R1# show ip route
Codes: L - local, C - connected, S - static, ...

      192.168.10.0/24 is variably subnetted, 2 subnets, 2 masks
C        192.168.10.0/24 is directly connected, GigabitEthernet0/0/0
L        192.168.10.1/32 is directly connected, GigabitEthernet0/0/0
      192.168.11.0/24 is variably subnetted, 2 subnets, 2 masks
C        192.168.11.0/24 is directly connected, GigabitEthernet0/0/1
L        192.168.11.1/32 is directly connected, GigabitEthernet0/0/1
      209.165.200.0/24 is variably subnetted, 2 subnets, 2 masks
C        209.165.200.224/30 is directly connected, Serial0/1/0
L        209.165.200.225/32 is directly connected, Serial0/1/0
```

---

## Az útvonal-kódok értelmezése

| Kód | Jelentés |
|---|---|
| **C** | Connected – közvetlenül csatlakoztatott hálózat |
| **L** | Local – a router saját IP-címe (admin távolság: 0) |
| **S** | Static – statikus útvonal |
| **R** | RIP – RIP routing protokolltól tanult |
| **O** | OSPF – OSPF routing protokolltól tanult |

---

## IPv6 útválasztási tábla ellenőrzése

```
R1# show ipv6 route
IPv6 Routing Table - default - 7 entries
Codes: C - Connected, L - Local, ...

C   2001:DB8:ACAD:1::/64 [0/0] via GigabitEthernet0/0/0, directly connected
L   2001:DB8:ACAD:1::1/128 [0/0] via GigabitEthernet0/0/0, receive
```

> **IPv6 helyi útvonal:** Az IPv4 /32-vel jelzi a helyi cím útvonalát; IPv6-ban ez **/128** prefixet jelent.

---

## Kapcsolat ellenőrzése ping-gel

```
R1# ping 2001:db8:acad:1::10
Sending 5, 100-byte ICMP Echos to 2001:DB8:ACAD:1::10...
!!!!!
Success rate is 100 percent (5/5), round-trip min/avg/max = 1/1/1 ms
```
