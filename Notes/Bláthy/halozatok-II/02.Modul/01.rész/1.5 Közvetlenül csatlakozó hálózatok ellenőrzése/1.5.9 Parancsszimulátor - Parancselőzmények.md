# 1.5.9 Parancsszimulátor – Parancselőzmények

## Feladat

Ebben a parancsszimulátoros feladatban a parancselőzmény funkciót kell használni.

---

## Megoldás

### 1. Az előzménypuffer méretének beállítása 200-ra

```
R1> terminal history size 200
```

### 2. A parancselőzmények megjelenítése

```
R1> show history
  show running-config | section line con
  show ip interface brief | include down
  show ip interface brief | exclude up
  show running-config | begin line
  terminal history size 200
  show history
```
