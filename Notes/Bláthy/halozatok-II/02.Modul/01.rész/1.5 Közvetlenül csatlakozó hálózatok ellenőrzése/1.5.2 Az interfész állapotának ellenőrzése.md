# 1.5.2 Az interfész állapotának ellenőrzése

## Az összes interfész gyors áttekintése

A `show ip interface brief` és `show ipv6 interface brief` parancsok egyetlen táblázatban mutatják az összes interfész állapotát.

### IPv4 ellenőrzés

```
R1# show ip interface brief
Interface              IP-Address      OK? Method Status                Protocol
GigabitEthernet0/0/0   192.168.10.1    YES manual up                    up
GigabitEthernet0/0/1   192.168.11.1    YES manual up                    up
Serial0/1/0            209.165.200.225 YES manual up                    up
Serial0/1/1            unassigned      YES unset  administratively down down
```

### IPv6 ellenőrzés

```
R1# show ipv6 interface brief
GigabitEthernet0/0/0   [up/up]
    FE80::7279:B3FF:FE92:3130
    2001:DB8:ACAD:1::1
GigabitEthernet0/0/1   [up/up]
    FE80::7279:B3FF:FE92:3131
    2001:DB8:ACAD:2::1
Serial0/1/0            [up/up]
    FE80::7279:B3FF:FE92:3130
    2001:DB8:ACAD:3::1
Serial0/1/1            [down/down]    Unassigned
```

---

## Hogyan értelmezzük az állapotokat?

| Status | Protocol | Jelentés |
|---|---|---|
| `up` | `up` | Az interfész működik ✓ |
| `up` | `down` | Fizikai kapcsolat van, de logikai hiba (pl. duplexitás) |
| `down` | `down` | Kábel nincs csatlakoztatva, vagy hardverhiba |
| `administratively down` | `down` | Manuálisan letiltva (`shutdown`) |

> Ha bármelyik interfész nem a várt állapotban van, az **konfigurációs vagy kábelezési problémát** jelez.
