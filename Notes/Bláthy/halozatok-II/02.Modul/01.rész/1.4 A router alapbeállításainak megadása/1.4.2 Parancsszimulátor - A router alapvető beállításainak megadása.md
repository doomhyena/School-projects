# 1.4.2 Parancsszimulátor – A router alapvető beállításainak megadása

## Feladat

Ebben a parancsszimulátorban az R2 router alapbeállításait kell elvégezni. A lépések ugyanazok, mint az R1 esetén (lásd: [[1.4.1 A router alapvető beállításainak megadása]]).

---

## Megoldás lépései

### 1. Globális konfigurációs mód és hosztnév

```
Router# configure terminal
Router(config)# hostname R2
```

### 2. Enable secret jelszó

```
R2(config)# enable secret class
```

### 3. Konzol vonali jelszó

```
R2(config)# line console 0
R2(config-line)# password cisco
R2(config-line)# login
R2(config-line)# exit
```

### 4. VTY vonali jelszó

```
R2(config)# line vty 0 4
R2(config-line)# password cisco
R2(config-line)# login
R2(config-line)# exit
```

### 5. Jelszavak titkosítása és MOTD banner

```
R2(config)# service password-encryption
R2(config)# banner motd #Authorized Access Only!#
```

### 6. Konfiguráció mentése

```
R2(config)# exit
R2# copy running-config startup-config
```
