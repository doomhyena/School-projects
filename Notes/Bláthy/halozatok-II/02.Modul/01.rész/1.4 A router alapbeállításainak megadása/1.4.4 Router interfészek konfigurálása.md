# 1.4.4 Router interfészek konfigurálása

## Mi szükséges egy interfész működéséhez?

Egy router interfésznek **három dolog** szükséges a működéshez:

1. **IP-cím** (IPv4 és/vagy IPv6)
2. **Aktiválás** – alapértelmezés szerint a LAN és WAN interfészek `shutdown` állapotban vannak → `no shutdown` parancs szükséges
3. **Leírás** (opcionális, de ajánlott) – max. 240 karakter

---

## Konfiguráció példa – R1 router interfészei

```
R1(config)# interface gigabitethernet 0/0/0
R1(config-if)# ip address 192.168.10.1 255.255.255.0
R1(config-if)# ipv6 address 2001:db8:acad:1::1/64
R1(config-if)# description Link to LAN 1
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface gigabitethernet 0/0/1
R1(config-if)# ip address 192.168.11.1 255.255.255.0
R1(config-if)# ipv6 address 2001:db8:acad:2::1/64
R1(config-if)# description Link to LAN 2
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface serial 0/0/0
R1(config-if)# ip address 209.165.200.225 255.255.255.252
R1(config-if)# ipv6 address 2001:db8:acad:3::225/64
R1(config-if)# description Link to R2
R1(config-if)# no shutdown
R1(config-if)# exit
```

---

## Mire figyelj konfiguráláskor?

- **LAN interfészek** (GigabitEthernet): alapértelmezés szerint `shutdown` → mindig add ki a `no shutdown` parancsot
- **WAN interfészek** (Serial): szintén `shutdown` alapból
- A `description` segít hibaelhárításkor azonosítani, melyik interfész hova csatlakozik
- Fizikailag is csatlakoztatni kell az interfészt egy másik eszközhöz, hogy valóban `up` legyen

---

## Az interfészek és az útválasztási tábla

Ha az interfészek aktívak (`up/up`), a router automatikusan felveszi az útvonalakat az útválasztási táblájába:
- **C** (connected) = közvetlenül csatlakoztatott hálózat
- **L** (local) = a router saját IP-címe
