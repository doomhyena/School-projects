# 1.4.6 IPv4-es loopback interfészek

## Mi az a loopback interfész?

A **loopback interfész** egy **szoftveres, virtuális interfész**, amely:
- Nincs hozzárendelve egyetlen fizikai porthoz sem
- Automatikusan `up` állapotban marad, amíg a router működik
- Soha nem "esik le" hardverhiba miatt

> **Analógia:** A loopback olyan, mint egy belső tükör a routernek – mindig elérhető, és saját magának is tud üzenetet küldeni.

---

## Mire használják?

| Felhasználás | Leírás |
|---|---|
| **Tesztelés** | Belső útvonalak és protokollok tesztelése fizikai kapcsolat nélkül |
| **Lab szimuláció** | Több loopback interfész létrehozásával hálózatokat szimulálhatunk |
| **Internet-szimuláció** | Tananyagokban az internet eléréséhez loopback interfészeket használunk |
| **Router ID** | Routing protokollok (pl. OSPF) loopback-et használnak router azonosítóként |

---

## Loopback interfész létrehozása

```
R1(config)# interface loopback 0
R1(config-if)# ip address 10.0.0.1 255.255.255.0
R1(config-if)# exit
```

A rendszer megerősíti a létrehozást:
```
%LINEPROTO-5-UPDOWN: Line protocol on Interface Loopback0, changed state to up
```

> Egy routeren **több loopback** interfész is létrehozható (`loopback 0`, `loopback 1`, stb.)
> Minden loopback IP-cím **egyedi** kell legyen – semmilyen más interfész nem használhatja ugyanazt.

---

## Ellenőrzés

```
R1# show ip interface brief | include Loopback
Loopback0    10.0.0.1    YES manual up    up
```
