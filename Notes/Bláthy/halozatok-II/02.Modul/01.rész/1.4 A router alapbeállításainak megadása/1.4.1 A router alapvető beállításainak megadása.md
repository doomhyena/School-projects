# 1.4.1 A router alapvető beállításainak megadása

## Router vs. Switch – miben hasonlóak?

A Cisco routerek és switch-ek sok szempontból hasonlóak:
- Ugyanolyan IOS-t futtatnak
- Ugyanolyan parancsstruktúrát használnak
- Az alapbeállítások lépései nagyrészt azonosak

> **A fő különbség:** A switch LAN-on belül mozgatja a forgalmat (2. réteg), a router pedig **hálózatok között** irányítja azt (3. réteg). Ha más hálózatba is el kell jutni az adatnak, routerre van szükség.

---

## Az alapbeállítások lépései

### 1. Az eszköz elnevezése

Az egyedi hosztnév segít azonosítani az eszközt a hálózaton:

```
Router(config)# hostname R1
R1(config)#
```

---

### 2. Jelszavak beállítása

```
R1(config)# enable secret [erős jelszó]
R1(config)# line console 0
R1(config-line)# password [jelszó]
R1(config-line)# login
R1(config-line)# exit
R1(config)# line vty 0 4
R1(config-line)# password [jelszó]
R1(config-line)# login
R1(config-line)# exit
R1(config)# service password-encryption
```

---

### 3. Belépési üzenet (MOTD banner) beállítása

A figyelmeztetés jogosulatlan hozzáféréssel szemben:

```
R1(config)# banner motd # Figyelmeztetés! Jogosulatlan hozzáférés tilos! #
```

---

### 4. Konfiguráció mentése

A változtatásokat a flash memóriában lévő `startup-config` fájlba kell menteni:

```
R1# copy running-config startup-config
```
