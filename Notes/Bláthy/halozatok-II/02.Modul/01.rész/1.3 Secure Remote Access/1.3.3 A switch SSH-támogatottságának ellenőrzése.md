# 1.3.3 A switch SSH-támogatottságának ellenőrzése

## Nem minden IOS támogatja az SSH-t

Az SSH engedélyezéséhez a switch-nek **kriptográfiai (titkosítási) képességekkel** rendelkező IOS verziót kell futtatnia. Ez az IOS fájl nevéből azonosítható.

---

## Az IOS nevének értelmezése

```
c2960-lanbasek9-mz.150-2.SE.bin
              ^^
              k9 = kriptográfiai csomag (SSH támogatott!)
```

Ha az IOS nevében **szerepel a „k9"** szövegrészlet, az SSH **támogatott**.

---

## Ellenőrzés a show version paranccsal

```
S1# show version
Cisco IOS Software, C2960 Software (C2960-LANBASEK9-M), Version 15.0(2)SE, ...
...
```

Ha a szoftvernév tartalmazza a **k9** betűket, a titkosítás elérhető.

---

## Az SSH-támogatás közvetlen ellenőrzése

```
S1# show ip ssh
SSH Enabled - version 2.0
Authentication timeout: 120 secs; Authentication retries: 3
```

Ha az IOS **nem támogatja** a titkosítási funkciókat, akkor a `show ip ssh` parancs ismeretlen parancsként jelenik meg:
```
S1# show ip ssh
                ^
% Invalid input detected at '^' marker.
```
