# 1.3.5 Az SSH működésének ellenőrzése

## Csatlakozás SSH-n keresztül

Az SSH-kapcsolat létrehozásához egy SSH-kliensprogram szükséges a számítógépen – pl. **PuTTY** (Windows), **Terminal** (macOS/Linux).

### Példa a csatlakozáshoz

Feltételek:
- Az SSH engedélyezve van az S1 switch-en
- A VLAN 99 SVI-hez a `172.17.99.11` IP-cím van rendelve
- A PC1 IP-címe: `172.17.99.21`

**PuTTY beállítások:**
- Host Name: `172.17.99.11`
- Port: `22`
- Connection type: `SSH`

Bejelentkezés után a felhasználónév/jelszó megadása szükséges:
```
login as: admin
admin@172.17.99.11's password: ccna
S1>
```

---

## Az SSH konfiguráció ellenőrzése

```
S1# show ip ssh
SSH Enabled - version 2.0
Authentication timeout: 120 secs; Authentication retries: 3
```

Ez a kimenet megerősíti, hogy az SSH **2-es verziója** van engedélyezve.

---

## Aktív SSH kapcsolatok megtekintése

```
S1# show ssh
Connection  Version  Mode  Encryption  Hmac         State         Username
0          2.0      IN    aes128-cbc  hmac-md5     Session started  admin
0          2.0      OUT   aes128-cbc  hmac-md5     Session started  admin
```
