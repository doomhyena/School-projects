# 1.3.4 Az SSH beállítása

## Az SSH konfigurálásának 6 lépése

Az SSH beállítása előtt a switch-en már be kell legyen állítva a **hosztnév** és a megfelelő **hálózati paraméterek**.

---

### 1. lépés – SSH-támogatás ellenőrzése

```
S1# show ip ssh
```

Ha a parancs ismeretlen, az IOS nem támogat SSH-t (nincs „k9" a névben).

---

### 2. lépés – IP domain-name beállítása

Az RSA kulcsok generálásához szükséges a domain-név:

```
S1(config)# ip domain-name cisco.com
```

---

### 3. lépés – RSA kulcspár generálása

Az RSA kulcsgenerálás egyben **automatikusan engedélyezi az SSH-t** is. A 1024 bites modulus ajánlott minimum:

```
S1(config)# crypto key generate rsa
How many bits in the modulus [512]: 1024
```

> Az SSH v2 kizárólagos engedélyezéséhez (ajánlott!):
> ```
> S1(config)# ip ssh version 2
> ```

> Az RSA kulcspár törléséhez (→ SSH automatikusan kikapcsol):
> ```
> S1(config)# crypto key zeroize rsa
> ```

---

### 4. lépés – Felhasználói hitelesítés beállítása

Helyi felhasználói adatbázis létrehozása:

```
S1(config)# username admin secret ccna
```

---

### 5. lépés – VTY vonalak konfigurálása

Engedélyezzük az SSH-t a VTY vonalakon (0-15), és tiltjuk a Telnetet:

```
S1(config)# line vty 0 15
S1(config-line)# transport input ssh
S1(config-line)# login local
S1(config-line)# exit
```

---

### 6. lépés – SSH v2 engedélyezése

```
S1(config)# ip ssh version 2
```

---

## A teljes konfigurációs összefoglaló

```
S1(config)# ip domain-name cisco.com
S1(config)# crypto key generate rsa
  → 1024
S1(config)# ip ssh version 2
S1(config)# username admin secret ccna
S1(config)# line vty 0 15
S1(config-line)# transport input ssh
S1(config-line)# login local
S1(config-line)# exit
```
