Az SSH konfigurálása előtt a switch-en legalább a hosztnevet és a megfelelő hálózati paramétereket be kell állítanunk.

Az SSH konfigurációs lépéseinek megismeréséhez kattintsunk az egyes gombokra!

1. lépés

	**Ellenőrizze az SSH-támogatást.** A **show ip ssh** paranccsal ellenőrizze, hogy a kapcsoló támogatja-e az SSH-t.
	
	Ha a kapcsoló által futtatott IOS nem támogatja a titkosítási funkciókat, akkor az eszköz ezt a parancsot nem fogja felismerni.

2. lépés

	 **onfigure the IP domain.**

	Configure the IP domain name of the network using the **ip domain-name** _domain-name_ global configuration mode command. In the figure, the _domain-name_ value is **[cisco.com](http://cisco.com/)**. 

3. lépés 

	 **Generate RSA key pairs.**
	Not all versions of the IOS default to SSH version 2, and SSH version 1 has known security flaws. To configure SSH version 2, issue the **ip ssh version 2** global configuration mode command. Egy RSA-kulcspár generálása automatikusan engedélyezi az SSH-t. Use the **crypto key generate rsa** global configuration mode command to enable the SSH server on the switch and generate an RSA key pair. Az RSA-kulcsok létrehozásakor a rendszergazdának meg kell adni a használni kívánt modulus hosszúságot. Az ábrán látható konfiguráció 1024 bites modulus-t használ. Hosszabb modulus használata sokkal biztonságosabb, de egyben hosszabb ideig is tart a kulcs előállítása és használata.
	
	**Note:** To delete the RSA key pair, use the **crypto key zeroize rsa** global configuration mode command. Miután az RSA-kulcspár törlésre kerül, az SSH-szerver automatikusan kikapcsol.

4. lépés 

	
	**Configure user authentication.**
	
	The SSH server can authenticate users locally or using an authentication server. To use the local authentication method, create a username and password pair using the **username** _username_ **secret** _password_ global configuration mode command. Az alábbi példában az "admin" felhasználóhoz a "ccna" jelszó lett hozzárendelve.

5. lépés

	 **Configure the vty lines.**
	
	Enable the SSH protocol on the vty lines by using the **transport input ssh** line configuration mode command. A Catalyst 2960 switch esetében a vty vonalak 0 és 15 között vannak. Ez a beállítás megakadályozza a nem SSH (például Telnet) kapcsolatokat, és egyedüli felügyeleti protokollnak az SSH-t engedélyezi. Use the **line vty** global configuration mode command and then the **login local** line configuration mode command to require local authentication for SSH connections from the local username database.

6. lépés 

	 **Enable SSH version 2.**
	
	By default, SSH supports both versions 1 and 2. When supporting both versions, this is shown in the **show ip ssh** output as supporting version 2. Enable SSH version using the **ip ssh version 2** global configuration command.
