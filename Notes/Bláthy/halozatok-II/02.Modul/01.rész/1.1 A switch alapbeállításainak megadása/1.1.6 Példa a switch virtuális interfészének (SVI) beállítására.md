# 1.1.6 Példa a switch virtuális interfészének (SVI) beállítására

## A konfiguráció menete

A felügyeleti IP-cím beállítása három lépésből áll:

---

### 1. lépés – A felügyeleti interfész konfigurálása

A VLAN 99 SVI-hez IPv4 és IPv6 cím hozzárendelése:

```
S1# configure terminal
S1(config)# interface vlan 99
S1(config-if)# ip address 172.17.99.11 255.255.255.0
S1(config-if)# ipv6 address 2001:db8:acad:99::1/64
S1(config-if)# no shutdown
S1(config-if)# exit
```

> **Megjegyzés:** A `VLAN 99` interfész csak akkor lesz `up/up` állapotú, ha:
> 1. Létrehoztuk a VLAN 99-et a switch-en
> 2. Van legalább egy eszköz csatlakoztatva egy VLAN 99-es porthoz

---

### 2. lépés – Alapértelmezett átjáró beállítása

Ha a switch-et **más hálózatból** is el akarjuk érni távolról, alapértelmezett átjárót kell beállítani:

```
S1(config)# ip default-gateway 172.17.99.1
```

> **Megjegyzés IPv6-ra:** Az IPv6 esetén nincs szükség manuális alapértelmezett átjáró beállítására, mert a switch azt a router hirdetményéből (RA üzenetből) kapja meg automatikusan.

> **Fontos:** Ha a Cisco Catalyst 2960 switch IOS 15.0 verziót futtat, előbb engedélyezni kell a dual-stack módot:
> ```
> S1(config)# sdm prefer dual-ipv4-and-ipv6 default
> S1(config)# end
> S1# reload
> ```

---

### 3. lépés – Konfiguráció ellenőrzése

```
S1# show ip interface brief
S1# show ipv6 interface brief
```

A kimenet megerősíti, hogy a VLAN 99 interfész IPv4 és IPv6 címmel is rendelkezik, és `up/up` állapotban van.

---

## Összefoglalás – SVI IP-konfiguráció

| Lépés | Parancs |
|---|---|
| Belépés az SVI interfészbe | `interface vlan [vlan-id]` |
| IPv4-cím beállítása | `ip address [cím] [maszk]` |
| IPv6-cím beállítása | `ipv6 address [cím/prefix]` |
| Interfész engedélyezése | `no shutdown` |
| Alapértelmezett átjáró | `ip default-gateway [cím]` |
| Ellenőrzés | `show ip interface brief` |
