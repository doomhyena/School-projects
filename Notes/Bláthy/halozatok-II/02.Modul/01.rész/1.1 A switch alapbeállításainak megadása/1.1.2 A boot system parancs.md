# 1.1.2 A boot system parancs

## Hogyan tudja a switch, melyik IOS-t töltse be?

A switch a rendszerindításkor a **BOOT környezeti változóban** tárolt elérési út alapján próbálja megtalálni az IOS-fájlt. Ha ez a változó nincs beállítva, a switch megpróbálja betölteni az első futtatható fájlt, amelyet a flash memóriában talál.

> A Catalyst 2960 esetén az IOS-fájl általában egy saját mappájában van, amelynek neve megegyezik a fájl nevével (a `.bin` kiterjesztés nélkül).

---

## A boot system parancs

A BOOT változó manuálisan beállítható a globális konfigurációs módból a `boot system` paranccsal:

```
S1(config)# boot system flash:/c2960-lanbasek9-mz.150-2.SE/c2960-lanbasek9-mz.150-2.SE.bin
```

### A parancs részei

| Rész | Jelentés |
|---|---|
| `boot system` | Maga a parancs |
| `flash:` | A flash memóriában kell keresni |
| `/c2960-lanbasek9-mz.150-2.SE/` | A mappa neve, ahol az IOS-fájl van |
| `c2960-lanbasek9-mz.150-2.SE.bin` | A konkrét IOS-fájl neve |

---

## Az indítási konfiguráció

Az IOS elindulása után a **startup-config** fájlból olvassa be az interfészek és a switch alapbeállításait. Ez a fájl `config.text` névvel a flash memóriában tárolódik.

---

## A jelenlegi BOOT-beállítás ellenőrzése

A jelenlegi rendszerindítási beállítást a `show boot` paranccsal lehet megtekinteni:

```
S1# show boot
BOOT path-list      : flash:/c2960-lanbasek9-mz.150-2.SE/c2960-lanbasek9-mz.150-2.SE.bin
Config file         : flash:/config.text
```
