# 1.1.4 Helyreállítás egy rendszerösszeomlás után

## Mikor van szükség erre?

Ha a switch IOS operációs rendszere **megsérült vagy hiányzik** (pl. sikertelen firmware-frissítés, fájlrendszer-hiba), a switch nem tud normálisan elindulni. Ilyenkor a **boot loader** parancssora nyújt segítséget, amelyen keresztül közvetlen hozzáférést kapunk a flash memóriához.

---

## Hogyan érjük el a boot loader parancssort?

A boot loader parancssor elérése **5 lépésből** áll:

**1. lépés:** Csatlakoztassunk konzolkábelt a PC-re, és indítsunk el egy terminál-emulátor szoftvert (pl. PuTTY, Tera Term).

**2. lépés:** Húzzuk ki a switch tápkábelét.

**3. lépés:** Dugjuk vissza a tápkábelt, majd a következő **15 másodpercen belül** nyomjuk le és tartsuk nyomva a **Mode** gombot – addig, amíg a SYST LED még zölden villog.

**4. lépés:** Tartsuk nyomva a Mode gombot, amíg a SYST LED röviden sárgává nem válik, majd visszavált tartósan zöldre – ekkor engedjük el.

**5. lépés:** A terminál ablakában megjelenik a boot loader prompt:
```
switch:
```

---

## Parancsok a boot loader módban

```
switch: help          (elérhető parancsok listája)
switch: set           (a BOOT változó és egyéb beállítások megjelenítése)
switch: flash_init    (flash fájlrendszer inicializálása)
switch: dir flash:    (a flash-en lévő fájlok és mappák listázása)
```

---

## Egy sérült IOS lecserélése

**1. Inicializáljuk a flash-t:**
```
switch: flash_init
```

**2. Listázzuk a fájlokat:**
```
switch: dir flash:
Directory of flash:/
    2  -rwx  11834846  <date>   c2960-lanbasek9-mz.150-2.SE8.bin
    3  -rwx  2072      <date>   multiple-fs
```

**3. Módosítsuk a BOOT változót az új IOS-ra:**
```
switch: BOOT=flash:c2960-lanbasek9-mz.150-2.SE8.bin
```

**4. Ellenőrizzük a változtatást:**
```
switch: set
BOOT=flash:c2960-lanbasek9-mz.150-2.SE8.bin
```

**5. Indítsuk el az IOS-t:**
```
switch: boot
```

---

## Mire képes még a boot loader?

| Feladat | Lehetséges? |
|---|---|
| Flash memória inicializálása | Igen |
| Flash formázása | Igen |
| Új IOS betöltése TFTP-ről | Igen |
| Elveszett jelszó visszaállítása | Igen |
| BOOT változó módosítása | Igen |
