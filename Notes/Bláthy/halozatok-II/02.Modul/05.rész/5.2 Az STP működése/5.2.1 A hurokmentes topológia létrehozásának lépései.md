# 5.2.1 A hurokmentes topológia létrehozásának lépései

## Az STP 4 lépése

Az STP hurokmentes topológiát épít fel egy **4 lépéses folyamat** során:

| Lépés | Tevékenység |
|---|---|
| **1** | Gyökérponti híd (root bridge) kiválasztása |
| **2** | Gyökérportok (root port) megválasztása |
| **3** | Kijelölt portok (designated port) megválasztása |
| **4** | Alternatív (blokkolt) portok kijelölése |

---

## A BPDU és a BID

A switch-ek **BPDU (Bridge Protocol Data Unit)** üzeneteket cserélnek egymással az STP döntéseinek meghozatalához. Minden BPDU tartalmaz egy **BID-et (Bridge Identifier)**, amely azonosítja a küldő switch-et.

### A BID felépítése

```
┌────────────────┬────────────────────┬──────────────────────┐
│  Bridge        │  Extended          │  MAC-cím             │
│  Priority      │  System ID         │  (switch)            │
│  (4 bit)       │  (12 bit)          │  (48 bit)            │
└────────────────┴────────────────────┴──────────────────────┘
```

| Mező | Leírás |
|---|---|
| **Bridge Priority** | Alapértelmezett: **32768**; tartomány: 0–61440 (4096-os lépésekben); kisebb érték = jobb |
| **Extended System ID** | A VLAN azonosítója – hozzáadódik a prioritáshoz (pl. VLAN 1 esetén 32768+1=**32769**) |
| **MAC-cím** | Ha a prioritás és az Extended System ID egyenlő, az **alacsonyabb MAC-cím** dönt |

---

## Miért fontos a BID?

A **legalacsonyabb BID-értékű switch** lesz a gyökérponti híd. A BID három mezőjét sorban hasonlítják össze:
1. Először a Bridge Priority + Extended System ID összege
2. Ha ez egyenlő → a MAC-cím alapján döntenek

---

## Az STP és az RSTP is BPDU-kat küld

- Az STP 2 másodpercenként küld Hello BPDU-kat
- A BPDU tartalmazza: a küldő BID-jét és a Root ID-t (gyökérponti híd BID-je)
- Ha egy switch nem kap BPDU-t a Max Age időzítőn belül → újraszámítás indul
