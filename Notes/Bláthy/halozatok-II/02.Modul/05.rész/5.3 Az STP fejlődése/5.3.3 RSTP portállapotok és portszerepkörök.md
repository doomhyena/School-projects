# 5.3.3 RSTP portállapotok és portszerepkörök

## RSTP portállapotok (3 állapot vs. STP 5)

Az RSTP az 5 STP-állapotot **3 állapotra** egyszerűsítette. A 802.1D letiltott, lezárt és figyelő (Disabled, Blocking, Listening) állapotok egyetlen **Discarding** állapotba olvadtak össze:

| RSTP állapot | Megfelelő STP állapot(ok) | Adatkeretek küldése? | MAC tanulás? |
|---|---|---|---|
| **Discarding** | Disabled + Blocking + Listening | ❌ Nem | ❌ Nem |
| **Learning** | Learning | ❌ Nem | ✅ Igen |
| **Forwarding** | Forwarding | ✅ Igen | ✅ Igen |

---

## RSTP portszerepkörök (4 szerepkör)

| Szerepkör | Leírás | Állapot |
|---|---|---|
| **Root port** | A legjobb útvonal a gyökérponti hídhoz | Forwarding |
| **Designated port** | A szegmens legjobb portja a gyökér irányában | Forwarding |
| **Alternate port** | Tartalék gyökérútvonal (ha a root port kiesik → azonnal Forwarding) | Discarding |
| **Backup port** | Tartalékos kijelölt port **megosztott médián** (hub); ritkán fordul elő | Discarding |

---

## Az Alternate port és a Backup port különbsége

| | Alternate port | Backup port |
|---|---|---|
| Mit tartalékol | A gyökérportot | Egy kijelölt portot |
| Jellemző topológia | Két switch között | Hubon (shared medium) |
| Mikor aktiválódik | Root port hiba esetén | A kijelölt port hiba esetén |

> A backup port ma már ritka, mivel a hubok elavult eszközök.

---

## Az Alternate port a gyors konvergencia kulcsa

```
STP-ben (802.1D):
  Root port kiesik → várakozás (Max Age 20s + Listening 15s + Learning 15s) → Forwarding
  Összesen: ~50 másodperc

RSTP-ben (802.1w):
  Root port kiesik → Alternate port AZONNAL Forwarding-ba lép
  Összesen: milliszekundumok
```
