# 5.3.2 Az RSTP alapjai

## Mi az RSTP?

Az **RSTP (Rapid Spanning Tree Protocol)** az IEEE **802.1w** szabvány, amely az eredeti STP (802.1D) gyorsabb változata. Az RSTP dramatikusan csökkenti az STP konvergencia idejét:

| | STP (802.1D) | RSTP (802.1w) |
|---|---|---|
| Konvergencia | **30–50 másodperc** | **Milliszekundumok** (tipikusan ~1-3 mp) |

---

## Visszafelé kompatibilitás

Az RSTP **visszafelé kompatibilis** az STP 802.1D-vel. Ha egy RSTP-s switch egy STP-s switch-csel kommunikál, automatikusan **visszavált 802.1D módra** az adott porton.

> Az STP terminológiája – pl. gyökérponti híd, BID, portköltség, portállapotok – az RSTP-ben is ugyanúgy érvényes. Az STP-t ismerő felhasználók egyszerűen átállhatnak RSTP-re.

---

## A Cisco Rapid PVST+

A Cisco saját **Rapid PVST+** implementációja az RSTP-re épül, de minden VLAN-hoz külön RSTP-példányt futtat.

```
S1(config)# spanning-tree mode rapid-pvst
```

---

## Hogyan gyorsul az RSTP?

Az RSTP az STP 5 portállapotát **3 állapotra** egyszerűsíti. Az **alternatív port** azonnal Forwarding-ba léphet, ha az aktív gyökérport meghibásodik – nincs Max Age 20 mp-es várakozás.

```
STP (802.1D): Max Age 20s → Listening 15s → Learning 15s → Forwarding
              ──────────────────────────────────────────────────────
              Összesen: ~50 másodperc

RSTP (802.1w): Alternate port azonnal Forwarding állapotba lép
              ──────────────────────────────────────────────────
              Összesen: milliszekundumok
```

---

## RSTP portállapotok áttekintése

| STP állapot | RSTP megfelelő |
|---|---|
| Disabled | Discarding |
| Blocking | Discarding |
| Listening | Discarding |
| Learning | Learning |
| Forwarding | Forwarding |
