# 5.3.4 PortFast és BPDU Guard

## A probléma: STP-késleltetés access portokon

Amikor egy PC vagy szerver csatlakozik egy access porthoz, az STP alapértelmezés szerint **30 másodpercig** késlelteti a port Forwarding állapotba lépését (Listening 15s + Learning 15s). Ez komoly problémát okozhat:

- DHCP-kliens nem kap IP-t → a DHCP-folyamat időtúllépés előtt lejár
- Lassú indulás a felhasználó számára
- Hálózati eszközök csatlakozásakor váratlan késés

---

## Mi az a PortFast?

A **PortFast** egy Cisco funkció, amely **access portokon** átugorja a Listening és Learning állapotokat, és azonnal **Forwarding** állapotba lép.

```
Normál STP:  Link UP → Listening (15s) → Learning (15s) → Forwarding
PortFast:    Link UP → ──────────────────────────────────→ Forwarding
```

> **Fontos:** A PortFastot **kizárólag access portokon** szabad alkalmazni (PC, szerver, nyomtató)!
> Trunk porton vagy switch-hez csatlakozó porton **feszítőfahurkot** okozhat!

---

## PortFast konfiguráció

Egyes porton:

```
S1(config)# interface fa0/6
S1(config-if)# spanning-tree portfast
```

Globálisan (minden access porton):

```
S1(config)# spanning-tree portfast default
```

---

## Mi az a BPDU Guard?

Ha egy PortFast-os access porton **BPDU-t kap a switch** → ez azt jelenti, hogy valaki **switch-et csatlakoztatott** oda (szándékosan vagy véletlenül). Ez **STP-hurkot** okozhat.

A **BPDU Guard** megoldja ezt: ha BPDU érkezik egy PortFast porton, azonnal **err-disabled** (hiba miatt letiltott) állapotba helyezi a portot. Csak **kézi beavatkozással** állítható helyre – ez szándékos biztonsági intézkedés.

---

## BPDU Guard konfiguráció

Egyes porton:

```
S1(config)# interface fa0/6
S1(config-if)# spanning-tree bpduguard enable
```

Globálisan (minden PortFast porton):

```
S1(config)# spanning-tree portfast bpduguard default
```

---

## Err-disabled port helyreállítása

Ha a BPDU Guard letiltotta a portot:

```
S1(config)# interface fa0/6
S1(config-if)# shutdown
S1(config-if)# no shutdown
```

---

## PortFast és BPDU Guard összefoglalás

| Funkció | Cél | Mikor aktiválódik | Hatás |
|---|---|---|---|
| **PortFast** | Gyors port-aktiválás access porton | Link felkapcsol | Átugorja Listening + Learning állapotot (30s megtakarítás) |
| **BPDU Guard** | Védelmi mechanizmus | BPDU érkezik PortFast porton | Port err-disabled állapotba kerül; csak kézzel állítható helyre |
