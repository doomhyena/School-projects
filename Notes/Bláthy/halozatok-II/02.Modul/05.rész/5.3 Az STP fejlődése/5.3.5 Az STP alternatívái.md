# 5.3.5 Az STP alternatívái

## Miért szükségesek alternatívák?

Az STP (és az RSTP) a redundáns kapcsolatokat **blokkolással** kezeli – a redundáns útvonalak logikailag inaktívak. Ez korlátozza a sávszélességkihasználást nagy méretű hálózatokban.

A modern vállalati LAN-ok és adatközpontok **hierarchikus háromrétegű modellben** épülnek fel (hozzáférési / elosztási / mag réteg), és több száz switch-et, ezernyi VLAN-t tartalmazhatnak.

---

## Hierarchikus LAN: Layer 3 routing váltja ki az STP-t

A megoldás: minél több helyen **Layer 3-ra emelni** a forgalomirányítást. A Layer 3 routing port-blokkolás nélkül kezeli a redundáns útvonalakat.

```
         Core réteg
      (Layer 3 routing)
      /               \
 Distribution      Distribution
 (Layer 3 / SVI)   (Layer 3 / SVI)
    /     \             /     \
 Access  Access     Access  Access
 (Layer 2)          (Layer 2)
```

- Az **access rétegben** STP fut (kis méret → gyors konvergencia)
- Az **elosztási és mag rétegekben** Layer 3 routing → STP-hurok nem keletkezhet

---

## Főbb STP-alternatívák

| Technológia | Leírás |
|---|---|
| **MLAG** (Multi-Chassis Link Aggregation) | Két switch virtuális switch-ként működik; redundáns uplink, STP nélküli terheléselosztás |
| **SPB** (Shortest Path Bridging – 802.1aq) | IEEE szabvány; minden link aktív; Dijkstra-algoritmus; adatközpont-fókusz |
| **TRILL** (Transparent Interconnection of Lots of Links) | IETF szabvány; IS-IS protokollal; minden elérési út aktív; „RBridge" eszközök |

> **Megjegyzés:** Ezek a technológiák meghaladják a tananyag kereteit; vállalati és adatközponti megvalósításokban alkalmazzák őket.

---

## Mikor maradj STP-vel?

Az STP (Rapid PVST+) **megfelelő választás**, ha:
- A hálózat viszonylag kis és közepes méretű
- A switch-ek Cisco IOS-t futtatnak
- A hálózati adminisztrátor ismeri az STP-t
- Nincs szükség extrém konvergencia-sebességre

---

## Az STP fejlődésének összefoglalása

```
STP (802.1D, 1990)
  │ → lassú (~50 mp), de alapozta meg a hurokelőzés elméletét
  ↓
RSTP (802.1w, 2001)
  │ → millisekundumos konvergencia; visszafelé kompatibilis
  ↓
Cisco Rapid PVST+ (IOS 15.0+)
  │ → per-VLAN RSTP; ajánlott Cisco hálózatokban
  ↓
MSTP (802.1s, 2002)
  │ → VLAN-csoportok; komplex, de hatékony nagy hálózatokban
  ↓
MLAG / SPB / TRILL
  → STP nélküli megoldások modern adatközpontokban
```
