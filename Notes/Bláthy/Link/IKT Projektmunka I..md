# 🌐 IKT Projektmunka I.

Az IKT Projektmunka I. tantárgy a Bláthy Ottó Villamosipari Technikumban a webfejlesztés alapjait tanítja, különös hangsúllyal a Visual Studio Code-ra, a HTML/CSS alapokra, a verziókezelésre és a reszponzív webdesignra.

## Mit fogsz itt tanulni?

A tantárgy az első leckével a fejlesztői eszközökkel (VS Code, Windows parancsok) indul. A CSS és HTML alapjain (02-03) haladsz tovább, ahol megismered a stíluslapok és struktúra alapjait. A képek és illusztrációk kezelése (04) és a verziókezelés (05, Git/GitHub) után reszponzív weboldalakat (06) és formázási technikákat (07) tanulsz.

## Ajánlott tanulási útvonal

A VS Code ismeretével (01) kezdd, majd haladj a CSS (02) és HTML+CSS (03) kombinációján át. A képek kezelése (04) és a verziókezelés (05) elengedhetetlen eszközök a projektmunkához. A reszponzív web (06) és formázás (07) a tananyag csúcsa — ezek után már egyszerű weboldalakat tudsz teljesen önállóan elkészíteni.
