### ⚙️ Futtatási útmutató / Usage guide

- **Cisco Packet Tracer**  
  **HU:** A hálózatos feladatok megnyitásához és futtatásához a `.pkt` fájlokat Cisco Packet Tracerben kell megnyitni.  
  **EN:** To open and run the networking assignments, open the `.pkt` files in Cisco Packet Tracer.

- **HTML / CSS / JavaScript**  
  **HU:** Nyisd meg az `index.html` vagy más `.html` fájlokat böngészőben.  
  **EN:** Open `index.html` or other `.html` files in a web browser.

- **Markdown / TXT**  
  **HU:** Nyisd meg tetszőleges szövegszerkesztőben vagy Markdown-megjelenítőben.  
  **EN:** Open them in any text editor or Markdown viewer.

- **XLSX / DOCX**  
  **HU:** Nyisd meg Microsoft Excelben / Wordben vagy kompatibilis irodai programban.  
  **EN:** Open them in Microsoft Excel / Word or in a compatible office suite.

### ⚙️ Futtatási útmutató / Usage guide

- **Python**  
  **HU:** `python3 fajlnev.py`  
  **EN:** `python3 filename.py`

- **C#**  
  **HU:** `dotnet run` vagy Visual Studio projektként  
  **EN:** `dotnet run` or open it as a Visual Studio project

- **Java**  
  **HU:** `javac Fajl.java`, majd `java Fajl`  
  **EN:** `javac File.java`, then `java File`

- **PHP**  
  **HU:** `php -S localhost:8000` vagy XAMPP segítségével  
  **EN:** `php -S localhost:8000` or by using XAMPP

- **HTML / JS / CSS**  
  **HU:** Nyisd meg az `index.html` fájlt böngészőben.  
  **EN:** Open `index.html` in a web browser.

- **SQL**  
  **HU:** Töltsd be a `.sql` fájlokat MySQL-ben vagy SQLite-ban.  
  **EN:** Load the `.sql` files into MySQL or SQLite.
